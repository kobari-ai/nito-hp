【2026年10月】Claudeの料金プランを比較｜Free・Pro・Max・Ultra・Teamの違いと選び方

執筆 岡村 希一（nito代表）

Claudeの料金でつまずきやすいのは、ドル表示なのに日本の消費税10%が含まれていることと、使える量が「1日◯回」ではなく5時間ごとの枠で決まることの2点です。

ここではAnthropicの料金ページ（2026年9月22日取得。APIクレジットは10月11日、Enterpriseの最低シート数は10月17日、MaxとUltraの区分は10月31日に確認）から、個人向けとチーム向けの金額、使用量の仕組み、プランごとに使えるモデルを並べます。ターミナルで使うClaude Code側の見方はClaude Codeの料金にまとめています。

この記事のポイント
  • 個人向けはFree $0・Pro $18・Max $110・Ultra $220。Proの$18は年払いの月額で、月払いなら$22
  • Ultraは週の使用量がProの10倍で、認証済みのアカウントには5時間の枠がない
  • Maxには月$100、Ultraには月$200のAPIクレジットが付く。使えるのはClaude Platformでの開発（API・Agent SDK）で、Claude Codeとアプリの追加使用量には使えない
  • 表示価格には消費税10%が含まれる（公式の注記は「Prices include 10% JCT」）
  • 個人向けで年払いを選べるのはProだけ。MaxとUltraは月払いのみ
  • 使用量は5時間のローリングの枠で決まり、有料プランには週次の上限が加わる（Ultraの認証済みアカウントは週次の上限だけ）。ウェブもClaude Codeも同じ枠から引かれる
  • Opus と Claude Code はProから。Freeで使えるのはSonnetとHaiku

個人向け4プランの金額

料金ページの「個人」タブに並ぶのは4つです。

プラン 月額 支払い方法
Free $0 課金なし
Pro $18（年払いの月額。$220を一括） 月払いなら$22
Max $110 月払いのみ
Ultra $220 月払いのみ

Proの$18は年間サブスクリプションの割引が入った月額で、請求は$220の一括です。月払いを選ぶと$22になります。これまでMaxの中で選んでいた「5x」と「20x」は、2026年10月にMaxとUltraという別のプランに分かれました。Ultraのヘルプによると、Max 20xはUltraに名前が変わり、契約中の人は同じ価格のままUltraに移ります。

表示価格に消費税が含まれている

料金カードの下に「Prices include 10% JCT」という一文があります。JCTは日本の消費税のことで、表示の$18や$22には10%の消費税がすでに乗っています。

米国向けのページの$20や$100は税別の金額で、日本からの請求にはその10%の消費税が加わります。円でいくらになるかは決済時の為替によって変わるため、金額を確定させたい場合は請求の履歴で確認してください。

使える量の決まり方

Claudeの上限は回数ではありません。公式ページによると、仕組みはこうです。

枠を消費するのはチャットだけではありません。ターミナルのClaude Codeで動かした分も同じプールから引かれます。会話の長さ、選んだモデル、使った機能で減り方が変わるため、公式も固定のメッセージ数を示していません。

公式はプラン間の差を倍率で示しています。Proは5時間あたりFreeの5倍以上、Maxは5時間ごとと毎週のどちらもProの5倍です。Ultraは週の使用量がProの10倍で、認証済みのアカウントには5時間の枠がありません。認証はアカウントや支払いの履歴から自動で行われ、済むまでは一時的な制限がかかります。現在の残量は設定の「使用状況」で確認できます。リセットの時刻の見方と、上限に達したときに取れる手はClaudeの使用制限とリセット時間の記事にまとめました。

Ultraの認証済みアカウントの見分け方と、Max 20xから移った人に変わることはClaude Ultraの記事で扱っています。

上限に達しても、有料プランなら使用クレジットをオンにしてAPIの標準レートで作業を続けられます。待つか、上げるか、従量で払うかの3択です。

プランごとに使えるモデルと機能

プラン選びに効くのは次の行です。

項目 Free Pro Max Ultra
5時間ごとの上限 制限あり 1x 5x なし（認証済み）
毎週の上限 制限あり 1x 5x 10x
Opus なし あり あり あり
Sonnet・Haiku あり あり あり あり
Fable なし 使用クレジット 週次制限の50% 週次制限の50%
Claude Code なし あり あり あり
Research なし あり あり あり
プロジェクト 最大5 あり あり あり
混雑時の優先アクセス なし なし あり あり
月間APIクレジット（Claude Codeには使えません） なし なし $100 $200
請求サイクル 該当なし 月払いと年払い 月払い 月払い

Fableは比較表に別枠で載っている上位のモデルで、Proでは使用クレジット、MaxとUltraでは週次制限の50%までという扱いになります。FreeとProの間にある壁は、OpusとClaude Codeです。この2つが必要なら、無料のままでは届きません。MaxとUltraがProと違うのは主に量で、混雑時の優先アクセスと新しい機能への早期アクセスが加わります。Claude Platformで開発に使える月間のAPIクレジットも、個人向けのプランではMaxとUltraにだけ付きます（Maxは月$100、Ultraは月$200）。2026年10月に料金ページに加わりました（10月11日に確認）。Claude Codeには使えません。受け取るにはClaude Consoleの組織をプランにリンクし、使わなかった分は翌月に繰り越されません。

コンテキストウィンドウは4プランとも「最大100万（モデルによって異なります）」で、プランで差が付いていません。Geminiは無料と有料でここが大きく変わるので、Claudeの特徴として覚えておく価値があります。モデルの学習にデータを使うかどうかは、どのプランもオプトアウトできます。

チームと会社で契約するとき

「Team & Enterprise」タブに切り替えると、Teamはシートの種類で金額が2つに分かれます。

区分 年払いのシート単価 月払い 中身
Team／スタンダード $22 $27.50 1セッションの使用量はProの1.25倍
Team／プレミアム $110 $137.50 1セッションの使用量はProの6.25倍
Enterprise $20＋APIレートの使用量 年払いのみ（最低20シート） SCIM・監査ログ・データ保持の設定

Teamは2席から150席までで、2種類のシートを混ぜて契約できます。会話は既定でモデルの学習に使われません。SSO・請求の一元化・コネクターの管理者コントロールはTeam以上に付き、個人向けのPro・Max・Ultraには付きません。Claude Fableはプレミアムシートなら週の使用量の50%までプラン内で使え、スタンダードシートでは使用クレジットの従量課金です。Claude Platformで使えるAPIクレジットも、シートごとに付きます（スタンダードは1席$20、プレミアムは1席$100、組織の合計で月$500まで）。2026年10月に料金ページに加わりました。Proとの違いやProから移るときの注意はClaude Teamプランの記事にまとめました。

Enterpriseはシートあたり$20に、使った分のAPIレートが乗る形です。使うモデルとタスクでコストが動きます。料金ページには年払いで最低20シートと書かれているため、20人に満たない組織はTeamを選ぶことになります。

このほか大学向けに教育プランがあり、学生・教員・スタッフを含む大学全体を対象に、割引料金、学習モード、専用のAPIクレジットが用意されています。

年払いはいくら安くなるのか

年払いがあるのはProとTeam、Enterpriseは年払いのみです。12か月使った場合の総額を並べると差が見えます。

区分 年払い 月払いを12か月 差
Pro $220 $264（$22×12） $44
Team／スタンダード（1シート） $264（$22×12） $330（$27.50×12） $66
Team／プレミアム（1シート） $1,320（$110×12） $1,650（$137.50×12） $330

年払いは1年分を一括で請求されます。月払いから年払いへ切り替える場合、未使用の期間は最初の年間請求書に充当されます。

返金は原則として受け付けていません。欧州経済領域と英国では14日間のキャンセル期間内であればアプリ内で返金をリクエストできて、それ以外の地域はヘルプから返金の資格を確認する形になります。

プランの変更と解約

個人プランの変更は設定の「お支払い」から、Teamはオーナーが組織設定から操作します。アップグレードの際、旧プランの残った価値が新プランの1請求期間のコストを上回ることがあり（Proの年払いからMaxの月払いに移る場合など）、その超過分はクレジットとして残って次の購入に自動で使われます。

解約してもチャットとプロジェクト、ファイルは残ります。消えるのは有料プランでしか使えない機能へのアクセスだけです。App StoreやGoogle Play経由で契約した場合は、Claudeの設定ではなくストア側から解約してください。

どのプランを選ぶか

判断は2段階です。まず、OpusかClaude Codeを使うか。使うならProまで上げる必要があります。次に、5時間の枠で足りているか。設定の使用状況を1〜2週間見て、上限に当たる日が続くならMaxです。Maxの5倍でも足りない人や、5時間の枠を気にせず長い作業を回したい人はUltraを選びます。

個人向けでは年払いはProだけです。MaxやUltraを長く使う前提でも、前払いで安くする選択肢は用意されていない点に注意してください。

複数人で使うなら、人数が2名でもTeamを選べます。管理機能が要るかどうかで、ProのままかTeamかが決まります。

よくある質問

金額は2026年9月22日時点の公式ページの表示で、消費税10%を含みます。MaxとUltraの金額は2026年10月31日に料金ページで確かめました。

Claudeの有料プランはいくらですか？

個人向けはProが月$18（年払いの月額、$220を一括）、月払いなら$22です。Maxは月$110、Ultraは月$220で、どちらも月払いのみです。表示価格には消費税10%が含まれます。

Claudeは無料でどこまで使えますか？

ウェブ・デスクトップ・モバイルでのチャット、ウェブ検索、ファイル作成、コード実行、会話をまたいだメモリ、アーティファクトの作成が使えます。プロジェクトは最大5つまでです。OpusとClaude Code、Researchは対象外です。

Claudeは1日に何回使えますか？

回数では決まりません。5時間のローリングの枠で上限が管理され、有料プランにはさらに週次の上限が加わります。Ultraの認証済みアカウントは5時間の枠がなく、週次の上限だけです。会話の長さや選んだモデルで減り方が変わるため、公式も固定のメッセージ数を示していません。

Proの月払いと年払いはどちらが得ですか？

年払いは$220の一括で、月額に直すと$18です。月払いは$22なので、12か月使うなら年払いのほうが$44安くなります。途中でやめる可能性があるなら月払いです。

MaxとProは何が違いますか？

量です。Maxは5時間ごとと毎週のどちらもProの5倍で、混雑時の優先アクセスが付きます。Claude Platformで使える月$100のAPIクレジットも付きますが、Claude Codeには使えません。そのほかの機能の顔ぶれはProと同じです。

MaxとUltraは何が違いますか？

Ultraは週の使用量がProの10倍で、認証済みのアカウントには5時間の枠がありません。月額は$220（Maxは$110）、APIクレジットは月$200（Maxは月$100）です。

Claude Codeは別料金ですか？

有料プランに含まれます。ただしチャットと同じ枠を共有するため、ターミナルで重い作業をするとチャット側の残量も減ります。作業量が多いときはConsoleのアカウントで従量課金のAPIクレジットに切り替えられます。

上限に達したらどうなりますか？

リセットを待つか、上位プランに移るか、有料プランなら使用クレジットをオンにしてAPIの標準レートで続けるかの3つです。現在の状態は設定の「使用状況」で確認できます。

Claudeを解約したらどうなりますか？

請求期間の終わりまではそのまま使えて、そのあとFree planに移ります。チャット、プロジェクト、ファイルはアカウントに残ります。次の請求を止めるなら、更新日の24時間前までに解約してください。

Enterpriseの料金はいくらですか？

シートあたり月$20に、APIレートでの使用量を加えた形です。年払いで最低20シートからの契約になり、Teamのすべての機能に加えてSCIM、監査ログ、カスタムデータ保持、ロールベースのアクセス制御が付きます。セルフサービスで始めることも、見積もりを依頼することもできます。
