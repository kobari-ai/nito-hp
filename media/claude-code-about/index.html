【2026年9月】Claude Codeとは？仕組み・できること・他のAIコーディングツールとの違い

執筆 岡村 希一（nito代表）

Claude Codeは、Anthropicが提供するコーディングエージェントです。ターミナルで動き、指示を受けるとプロジェクトの中のファイルを自分で探して読み、編集し、コマンドを実行してテストまで回します。公式ドキュメントは「ターミナルで実行されるagenticアシスタント」と説明しており、コーディング以外でも、コマンドラインからできることなら支援できると書かれています。

ChatGPTやClaudeのチャットにコードを貼って相談するのとは、性質が違います。この記事はClaude Codeの仕組み、概要、セキュリティの各ページ（2026年9月19日取得）を一次ソースに、何をするものなのか、どう動いているのか、他のAIコーディングツールと何が違うのかを整理します。インストールや操作の手順は使い方の記事、料金は料金プランの記事にあります。

この記事のポイント
  • Claude Codeはagenticループ（コンテキストの収集 → アクションの実行 → 結果の検証）を回して仕事を終わらせるツール。コードを提案して終わりではない
  • ループを動かすのはモデルとツールの2つ。ツールはファイル操作・検索・実行・ウェブ・コードインテリジェンスの5カテゴリ
  • チャット型（貼り付けて相談）・補完型（書いている横で提案）と違い、プロジェクト全体を見て複数ファイルを変更する
  • 無料プランでは使えない。Pro（月$22）以上かAPIの従量課金が必要
  • ファイル編集の前にスナップショットを取るため、Escを2回押せば直前の状態に戻せる。権限モードで任せる範囲も決められる

Claude Codeとは

公式ドキュメントの概要は、Claude Codeを「コードベースを読み取り、ファイルを編集し、コマンドを実行し、開発ツールと統合するagentic codingツール」と説明しています。名前にCodeと付きますが、動くのはコードの中だけではなく、ドキュメントの作成やファイルの整理など、コマンドラインからできる作業全般が対象です。

チャットのClaude Claude Code
入力 質問・貼り付けたコード 目標（「このバグを直して」）
ファイル 添付したものを読む プロジェクトの中を自分で探して読み書きする
コマンド 実行できない 実行できる（許可の上で）
出力 文章・コードの提案 変更されたファイル、実行されたテスト
使う場所 ブラウザ・アプリ ターミナル・VS Code・デスクトップアプリ・ウェブ

どちらもAnthropicの製品で、中身の言語モデルも共通です。周りにツールとループが付いているかどうかが、両者を分けています。チャット画面のClaudeの使い方は別記事にまとめています。

仕組み: agenticループと5つのツール

公式ドキュメント「Claude Codeの仕組み」は、タスクを渡されたClaudeがコンテキストの収集 → アクションの実行 → 結果の検証の3つのフェーズを通って働く、と説明しています。

「失敗しているテストを修正して」と頼まれたとき、Claude Codeは公式ドキュメントの例では次のように動きます。

  1. テストスイートを実行して、何が失敗しているかを確認する
  2. エラー出力を読む
  3. 関連するソースファイルを検索する
  4. それらのファイルを読んでコードを理解する
  5. ファイルを編集して問題を修正する
  6. テストを再度実行して検証する

どのツールを使うかは、プロンプトとその時点で分かっていることからClaude自身が選びます。ループは依頼の内容によって伸び縮みし、コードベースへの質問なら収集だけで終わることもあります。途中で止めて方向を変えるのも前提の設計です。Escを押せばその場で止まります。

ループを動かすのは推論するモデルと、行動するツールの2つです。組み込みツールは5つのカテゴリに分かれます。

カテゴリ できること
ファイル操作 ファイルの読み取り、コード編集、新規作成、名前変更と再編成
検索 パターンでファイルを検索、正規表現で内容を検索、コードベースを探索
実行 シェルコマンドの実行、サーバー起動、テスト実行、gitの操作
ウェブ ウェブ検索、ドキュメントの取得、エラーメッセージの検索
コードインテリジェンス 編集後の型エラーと警告の表示、定義へのジャンプ、参照の検索（プラグインが必要）

公式ドキュメントは「ツールがなければ、Claudeはテキストで応答することしかできません。ツールがあれば、Claudeはアクションを実行できます」と書いています。

Claude Codeがアクセスできるもの

あるディレクトリで claude と打って起動したとき、Claude Codeが見られるものは公式ドキュメントに列挙されています。

対象 内容
プロジェクト ディレクトリとサブディレクトリ内のファイル、許可した他の場所のファイル
ターミナル 実行できるあらゆるコマンド。ビルドツール、git、パッケージマネージャー
gitの状態 現在のブランチ、コミットされていない変更、最近のコミット履歴
CLAUDE.md プロジェクト固有の指示・規約を書いたファイル。毎セッションの開始時に読まれる
自動メモリ 作業中にClaudeが保存した学び。各セッションの開始時に先頭200行または25KBまで読まれる
拡張機能 MCPサーバー、スキル、サブエージェント、Claude in Chrome

プロジェクト全体が見えているので、「認証のバグを直して」と頼めば、関連ファイルを検索して複数のファイルにまたがる修正ができます。ここが、開いているファイルしか見ていない補完型のツールとの差です。

他のAIコーディングツールとの違い

AIでコードを書くツールは大きく3つの型に分かれます。3つを分ける軸が誰が次の一手を決めるかです。

型 動き 人の役割
補完型 書いている横で次の行やブロックを提案する 採用するか決め、自分で書き進める
チャット型 貼り付けたコードについて相談に答える コードを貼り、答えを自分で反映する
エージェント型（Claude Code） 目標を渡すと、ファイルを探して読み、編集し、コマンドを実行して検証する 目標を決め、要所で承認し、必要なら止めて方向を変える

同じエージェント型の中での違いは、どこで動くか（ターミナル・エディタ・クラウド）、どのモデルを使うか、権限の仕組みがどうなっているか、に分かれます。Claude Codeの場合、ターミナル、VS Code・JetBrains拡張、デスクトップアプリ、claude.ai/code、Slack、CI/CDから使え、実行環境もローカル・クラウド・リモートコントロールの3つが選べます。agenticループもツールも、どこから使っても同じだというのが公式ドキュメントの説明です。

公式ドキュメントとクイックスタートに例として挙げられているものを整理すると、次の8つになります。

できること 頼み方の例
コードベースの説明 「このプロジェクトは何をしていますか？」「入口になるファイルはどれ？」
機能の追加 「ユーザー登録フォームに入力検証を追加して」

リファクタリング 「認証モジュールをasync/awaitに書き換えて」

コードのないフォルダでも動く点も特徴です。公式ドキュメントの一般的なワークフローには「ノートと非コードフォルダで作業する」という節があり、Markdownのメモや資料のフォルダで使う例が案内されています。

料金と使える条件

Claude Codeは無料プランでは使えません。Claude Pro（月$22、年払いなら月$18）以上のプランに入るか、APIの従量課金で使います。日本向け料金ページは消費税込みの表示です。

プラン 月額（消費税込み） Claude Code
Free $0 使えない
Pro $22（年払いは月$18） 使える
Max $110／$220 使える（Proの5倍／20倍の使用量）
Team・Enterprise 1シート$27.50〜 使える
API 従量課金 使える

使用量の上限は5時間ごとの枠と1週間の枠の2段構えで、claude.aiのチャットとClaude Codeが同じ枠を使います。上限に当たったときの選択肢や、APIの単価は料金プランの記事に詳しく書いています。

勝手に壊されないための仕組み

「AIが自分でコマンドを実行する」と聞いて最初に気になるのは安全性です。Claude Codeには3つの層があります。

  • 権限モード: Manualモードでは読み取り専用で始まり、ファイルの編集やコマンドの実行の前に毎回確認が出ます。Shift+Tabで切り替えられ、編集だけ自動で受け入れるモード、読むだけで計画を出すモードもあります
  • チェックポイント: ファイル編集の前に現在の内容のスナップショットを取るので、Escを2回押せば直前の状態に戻せます。gitとは別に保持され、会話を再開しても使えます
  • 作業ディレクトリの境界とサンドボックス: Manualモードでは起動したフォルダとその下にしか書き込めず、サンドボックス化したbashではファイルシステムとネットワークを分離して実行します

公式のセキュリティページには「Claude Codeは、ユーザーが付与したパーミッションのみを持ちます。承認前に、提案されたコードとコマンドのセキュリティを確認する責任があります」と書かれています。自動で進む範囲を広げるほど、人が事前に確認できる量は減る、という関係です。

向いている人・向いていない人

向いている 向いていない
複数ファイルにまたがる修正が多い人 1行ずつ提案してほしい人（補完型のほうが合う）
テストやビルドまで含めて任せたい人 提案を読んで自分で書きたい人
定型作業をコマンドや手順書ごと自動化したい人 無料で使いたい人（Pro以上が必要）
ターミナルでの作業に抵抗がない人 GUIだけで完結させたい人（デスクトップアプリなら可）
コード以外のファイル整理にも使いたい人 取り消せない操作を承認なしで任せたい人

プログラミングをしない人の用途としては、議事録の整形やフォルダの整理があります。その場合はターミナルよりデスクトップアプリのほうが入りやすく、具体的な手順は使い方の記事に書いています。

よくある質問

Googleの「他の人はこちらも質問」に出ている質問が中心です。

Claude Codeとは何ですか？

Anthropicが提供するコーディングエージェントです。ターミナルやエディタから使い、目標を伝えるとプロジェクトのファイルを自分で探して読み、編集し、コマンドを実行して結果を確かめます。公式ドキュメントの言葉では「ターミナルで実行されるagenticアシスタント」です。

Claude Codeは何ができますか？

コードベースの説明、機能の追加、バグの修正、リファクタリング、テストの作成と実行、gitの操作、ドキュメントの更新、コードレビューができます。コードのないフォルダでMarkdownのメモや資料を扱うことも公式に案内されています。

Claude Codeは無料ですか？

無料では使えません。Claude Pro（月$22、年払いなら月$18）以上のプランか、APIの従量課金が必要です。日本向け料金ページの表示です。

Claude Codeの何がすごいのですか？

プロジェクト全体を見て、複数のファイルにまたがる変更を自分で進め、テストの実行まで含めて検証まで回る点です。提案を受け取って人が反映する従来の使い方と違い、作業そのものが終わった状態で返ってきます。

ClaudeとClaude Codeの違いは何ですか？

Claudeはブラウザやアプリで使うチャット型のAI、Claude Codeはターミナルやエディタで動くエージェントです。中身のモデルは共通ですが、Claude Codeにはファイル操作やコマンド実行のツールと、結果を確かめて次を決めるループが付いています。

Claude Codeは日本語で使えますか？

使えます。指示も応答も日本語で問題ありません。常に日本語で答えてほしい場合は、~/.claude/CLAUDE.md に「日本語で答える」と書いておくと、すべてのプロジェクトで有効になります。

Claude Codeで勝手にファイルを壊されませんか？

既定の設定ではファイルの書き込みやコマンドの実行の前に確認が出ます。編集前のスナップショットも取られるので、Escを2回押せば直前の状態に戻せます。Manualモードでは起動したフォルダとその下にしか書き込めません。

Claude CodeはWindowsでも使えますか？

使えます。Windows 10 1809以上またはWindows Server 2019以上が対象で、PowerShellからインストールします。WSLでもmacOSと同じ手順で導入できます。
