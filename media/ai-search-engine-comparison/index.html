【2026年9月】AI検索エンジン4種を実測比較｜ChatGPT・Perplexity・Gemini・AIモードの引用と回答の違い

執筆 岡村 希一（nito代表）

ChatGPT・Perplexity・Gemini・GoogleのAIモードの4つに、同じ5つの質問を2026年9月20日に投げて、返ってきた回答と出典を数えました。 同じ質問でも、出典の数も回答の長さも大きく違います。

測ったのは出典に出てきたドメインの数、回答の長さ、そして引用元が公式ページなのか比較サイトなのかという内訳です。使う側の「どれを選ぶか」と、サイトを持つ側の「どこに引用されるか」の両方から読める形にしました。

この記事のポイント
  • 出典の数はPerplexityとChatGPTが多い（実測の中央値: Perplexity 16ドメイン、ChatGPT 12、AIモード 4、Gemini 4）
  • 回答の長さは逆。Perplexity 2,788字、AIモード 1,427字、Gemini 1,083字、ChatGPT 333字（いずれも中央値）
  • 公式・一次ソースを引く比率はChatGPTとPerplexityが高い（45ドメイン中7と6。AIモードとGeminiは各1）
  • 「どれが一番」ではなく質問の種類で選ぶ。短く早く知るならChatGPT、根拠まで確かめるならPerplexity、検索のついでに読むならAIモード
  • サイト側の示唆: 同じ質問でも引用されるサイトはAIごとに違う。1つのAIで出ないことは、全部で出ないことを意味しない

測り方

nitoが日常的に使っているAI検索の実測ツール（4つのAIに同じ質問を投げて、回答と出典を記録する仕組み）で、2026年9月20日に次の5つの質問を投げました。

# 質問 質問の種類
1 2026年9月時点で、日本で使える電子帳簿保存法に対応した会計ソフトのおすすめは？ 商品の比較
2 Claude Code と Cursor はどちらが初心者向き？違いを教えて ツールの比較
3 東京都内で法人向けにLLMO（AI検索対策）を支援している会社を教えて 会社探し
4 AIによる概要（Google）を非表示にする方法は？ 手順の確認
5 今週のAI関連の主なニュースを3つ教えて 最新情報

記録したのは回答の本文、出典として提示されたURL、そしてAIが裏で実行した検索クエリ（取得できるものだけ）です。各AIとも既定のモードで、無料・有料の切り替えや検索機能の手動オンオフはしていません。GeminiとPerplexityは5問のうち2問で取得に失敗したので、集計は取得できた分だけで出しています。取得できなかった2問は計測側の失敗で、そのAIが答えられなかったわけではありません。

実測の結果

取得できた問 出典ドメイン数（中央値・範囲） 回答の長さ（中央値） 出典の総数 うち公式・一次
ChatGPT 5 / 5 12（0〜17） 333字 45 7
Perplexity 3 / 5 16（11〜18） 2,788字 45 6
GoogleのAIモード 5 / 5 4（0〜11） 1,427字 23 1
Gemini 3 / 5 4（4〜5） 1,083字 13 1

「公式・一次」は、出典のドメインがサービスの公式サイトや提供元のヘルプ（support.google.com、anthropic.com、claude.com、cursor.com、会計ソフト各社の公式サイトなど）だったものを数えたものです。

① 出典の数と回答の長さは連動しない。 ChatGPTは出典を12ドメイン提示しながら、回答は333字と最も短いです。要点だけを短く返し、根拠はリンクで示す形です。Perplexityは出典16ドメインで回答2,788字と、どちらも最多でした。

② AIモードとGeminiは出典が少ない。 どちらもGoogleの製品ですが、実測では出典として提示されたドメインが4前後でした。回答は1,000字を超える一方、根拠の幅は狭くなります。

③ 引用元の種類が違う。 ChatGPTは45ドメイン中7、Perplexityは45中6が公式や提供元のページでした。AIモードとGeminiは、比較サイトやまとめ記事が中心です。

質問の種類で結果が変わる

平均の傾向とは別に、質問ごとの結果も並べます。

質問 出典が多かった 回答が長かった 特徴
会計ソフトのおすすめ Perplexity 18 Perplexity 3,555字 Perplexityは裏で45回の検索を実行。ChatGPTは出典0で要約のみ
Claude Code と Cursor ChatGPT 17 AIモード 1,795字 ChatGPTは公式ドキュメントと個人ブログを併用。AIモードは出典0で長文

「会社を探す」質問では、4つのAIとも回答しましたが、名前が挙がった会社はほとんど重なりませんでした。同じ検索意図でも、AIごとに参照する情報源が違うためです。

使う側の選び方

実測から言える使い分けは次のとおりです。

用途 向いているAI 理由
事実を早く確認したい ChatGPT 回答が短く、出典のリンクが多い。読む時間が最小
根拠まで確かめたい Perplexity 出典が最多で、回答も詳しい。裏で何十回も検索する
検索のついでに答えを読みたい GoogleのAIモード 検索結果の画面で完結する。回答は1,000〜1,800字で、出典は少ない
文章の作成まで続けたい Gemini・ChatGPT 調べたあとにそのまま書かせる流れが自然
最新のニュース ChatGPT 出典15ドメインで海外メディアまで広く引いた

「AIで1番優秀なのはどれか」は、測る軸で答えが変わります。出典の数で選ぶならPerplexity、回答の短さならChatGPT、検索の画面で完結するのはAIモードでした。4つとも無料で試せます。各サービスの回答の出方の違いはAI検索の出方の比較記事にも書いています。

サイトを持つ側への示唆

ここからは企業のサイト運営の話です。実測から見えた点が3つあります。

① 引用元はAIごとに重ならない。 会社を探す質問では4つのAIが合わせて30以上のドメインを引用しましたが、複数のAIに共通して出たのは数件でした。自社が1つのAIで出ないからといって、すべてで出ないわけではありません。

② 公式・一次ソースを引くAIと、まとめ記事を引くAIがある。 ChatGPTとPerplexityは公式サイトを引く比率が高く、AIモードとGeminiは比較サイトやまとめ記事が中心でした。自社サイトを整えるだけでなく、業界のまとめ記事に載っているかどうかも、AIによっては効きます。

③ 出典が少ないAIほど、載るかどうかの差が大きい。 出典が4件しかない場面で選ばれるかどうかは、16件あるうちの1件に入るよりずっと厳しい条件です。AIモードやGeminiで引用を狙うなら、その質問でよく引かれているまとめ記事に載るほうが早い、という関係になります。

測り方は自社の顧客がしそうな質問を5つ決めて、この記事と同じように4つのAIへ同じ文で投げるだけです。考え方はAI検索対策（LLMO）の記事にまとめています。

よくある質問

Googleの「他の人はこちらも質問」に出ている質問が中心です。

おすすめのAI検索エンジンは？

目的で変わります。根拠まで確かめたいならPerplexity（実測で出典16ドメイン・回答2,788字）、短く早く知りたいならChatGPT（333字）、検索のついでに読むならGoogleのAIモードです。どれも無料で試せます。

AIで1番優秀なのはどれですか？

測る軸で変わるため、1つには決まりません。出典の数ならPerplexity、回答の短さならChatGPTが実測では上で、AIモードは検索の画面で完結する点が違いです。自分がよくする質問を1つ決めて、同じ文を投げ比べるのが確実です。

無料の1番いいAIは？

今回測った4つはいずれも無料で使えます。無料の範囲で見ると、出典の多さならPerplexity、検索のついでに使えるのはGoogleのAIモードです。回数や高度な機能に制限がある点は各サービスで異なります。

PerplexityとChatGPTのどちらがいいですか？

実測でのPerplexityは出典16ドメイン・2,788字で根拠を広く集め、ChatGPTは出典12ドメイン・333字で要点を短く返しました。調べものの深さならPerplexity、読む時間の短さならChatGPTです。

AI検索エンジンと従来の検索の違いは何ですか？

従来の検索はキーワードに合うページの一覧を返し、AI検索は質問の意味を解釈して回答そのものを返します。AI検索は回答の下に参照したサイトを示すので、サイト側は「上位に出る」だけでなく「引用される」ことが必要になります。

GoogleのAIによる概要とAIモードは違いますか？

違います。AIによる概要は通常の検索結果の最上部に自動で出る要約、AIモードは専用タブで会話しながら掘り下げる機能です。詳しくはAIによる概要の記事とAIモードの記事に書いています。

自社がAI検索で引用されているか調べる方法は？

顧客がしそうな質問を5つ決めて、4つのAIに同じ文で投げ、社名が出るか、どのサイトが引用されているかを記録します。AIごとに引用元が違うので、1つだけで判断しないことが大切です。月に1回同じ質問で測ると、変化が追えます。
