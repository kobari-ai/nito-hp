BtoBでLLMO対策の会社選びが重要な理由は？

BtoBの買い手の多くは売り手に連絡する前に候補をリストアップしており、その洗い出しにAIを使う人も多いためです。依頼先によって、その段階に届く施策の範囲が変わります。

HubSpot Japanが2026年6月に、従業員50名以上の企業でBtoB商材の購買に関わった1,573名に聞いた調査では、売り手に接触する人（1,431名）のうち63.5%が、接触の時点で複数の候補のリストアップか、それより先の段階まで進んでいました。AIを使う買い手の約半数（50.3%）は、候補の洗い出しにAIを使っています。

AIがまとめた情報は信頼できる情報の順位が最下位（37.8%）ですが、約4人に1人（24.9%）は、AIで得た情報をそのまま、またはほぼそのまま社内説明や稟議に使っています。買い手が最も信頼するのは価格・追加費用・契約条件が明瞭な情報（60.6%）で、最初に売り手へ連絡する目的も「価格・見積もりを確認するため」（42.4%）が最多でした。AIの回答で候補に挙がることと、料金や条件を確認できるページが自社にあることの両方が、商談に進めるかを左右します。

自社がAIにどう紹介されているかを先に確認しておくと、外部の言及と自社サイトのどちらが足りないかが分かり、依頼範囲を決めやすくなります。

外部の言及をどこまで扱うか

PRや比較メディアへの掲載を施策の中心に置くか、自社サイトの整備を中心に置くかは会社ごとに重心が違います。IDEATECHは調査リリースとパブリシティの獲得を主の領域とし、andmediaは自社のBtoB比較メディアと外部メディアへの掲載営業を持っています。エイチリンクは比較・おすすめ記事への掲載交渉を月22万円以上のプランの代行に含めています。

AIが参照する比較記事やメディアの記事は、自社では書き換えられません。比較の質問で他社の記事ばかりが読まれているなら、外部に強い会社が候補です。まずは依頼候補に、掲載営業の担当と対象メディアを聞いてみましょう。一方で外部の掲載は相手のあることなので、どのプランに掲載営業が入り、結果を保証しないことまで確認しておく必要があります。公式で、andmediaは掲載や成果を保証しないと書いています。

実装まで受けるか

指示書や要件定義までの会社と、ページの改修や記事の制作まで担う会社があります。LANYは施策の要件定義と実行ディレクションまでをコンサルティングの範囲とし、実装は貴社か制作会社、または別の実行支援サービスで受ける形です。andmediaはサイト構造について改善指示書を出し、記事や事例記事の制作はActionプラン以上で選んで実行します。

社内にサイトを修正できる担当者や付き合いのある制作会社がいるなら、方針と指示書に強い会社でも進みます。マーケ担当が1人で、更新まで手が回らない会社は、制作と実装まで月額に入る会社のほうが進めやすくなります。

成果を商談の件数で見るか

言及率は途中の目印として使えますが、BtoBで最後に見たいのは問い合わせと商談です。andmediaはAIからの流入と、フォームで「AI検索」と答えた件数を分けて確認すると書き、IDEATECHはMAツールでAI経由の問い合わせ数と商談化率まで追います。LANYはLLM経由の流入数とコンバージョン数を継続して見る体制で、エイチリンクは毎月の定例で有効な問い合わせの数を報告する進め方です。

AIで社名を知った人は検索し直してからサイトに来ることがあり、アクセス解析の参照元だけでは計測しきれません。問い合わせフォームに知ったきっかけを聞く項目があるか、商談の記録とどうつなぐかまで提案に入っている会社を選ぶと、施策の効果を営業の数字で話せます。

Google検索のうち、llms.txtなどAI向けのファイルの作成や不自然な言及の追求は、無視できる戦術だとGoogleの最適化ガイドは説明しています。外部への掲載を頼むなら、掲載先が買い手の比べる記事として自然に読まれるかも確認しましょう。

2. 株式会社IDEATECH（IDEA LLMO）

IDEATECHはBtoBの企業の広報・PRを支援してきた会社で、IDEA LLMOを「BtoB向けLLMO戦略支援」として出しています。調査企画2,500件以上、Yahoo!ニュースへの掲載300件以上を公式に掲げ、調査リリースと業界紙・専門紙への露出で第三者の言及を積み上げる進め方です。

もう1つの柱は業界での選び方そのものを調査データで示すことです。コラムや公式サイトの記事、FAQ付きの選定基準のLPも実行支援に含まれます。計測はIDEA LLMO BOARDで、ChatGPT・Gemini・Copilot・Perplexityの回答を、社名を含む質問と含まない質問に分けて毎月同じ条件で取る仕組みです。自社で調査データを持たず、業界メディアでの露出から増やしたい会社に向いています。

3. andmedia株式会社（and AEO）

andmediaはSEOとコンテンツ制作の会社で、and AEOは「BtoB企業のためのAEO（AIO）対策」をうたうサービスです。複数のBtoB比較メディアを自社で持ち、AIが引用している記事を特定して掲載を獲得する施策と、プレスリリースや第三者記事を増やす施策を組み合わせます。

料金を4つのプランで公開し、狙う質問の設計は12問（Scaleは22問）、AIからの流入とフォームの回答を分けて見るダッシュボードも用意しています。公式には顧客単価10万円以上のBtoB商材に向くと書かれており、金額と範囲を先に把握して稟議を通したい会社に合います。

4. 株式会社LANY

LANYはSEOを中心に300社以上を支援してきたデジタルマーケティングの会社です。LLMOコンサルティングでは、最初の約1ヶ月で狙う質問の調査と策定、質問ごとにAIがどのブランドを選ぶかの分析、ロードマップとモニタリング用のダッシュボードの作成までが最初の工程です。

施策の候補は公式サイトやコンテンツに限らず、広告・比較メディア・PR・第三者情報まで横断して優先度を付けます。制作会社を交えた3社体制での実績もあり、BtoBマーケティング支援やホワイトペーパー制作も別のメニューにあります。実装は社内や制作会社で受け持ち、戦略と優先順位を固めたい会社に向いています。

5. エイチリンク株式会社

エイチリンクは従業員10名以下のBtoB中小企業のホームページ集客に絞った会社です。月22万円（税別）のプランでSEOとLLMO対策、サービスページやFAQの改修、構造化データの実装、ホームページの新規制作までを代行し、比較・おすすめ記事への掲載交渉も含みます。

初期費用0円で最低契約期間がなく、毎月の定例では有効な問い合わせの数とAIでの紹介のされ方を報告する進め方です。Webの専任がおらず、社長が決めてすぐに動かしたい小規模なBtoB企業に向いています。

6. 株式会社シャコウ

シャコウはBtoBのマーケティングと営業の支援を専門にする会社で、総合型SEO・LLMO支援を出しています。競合調査・ペルソナ・カスタマージャーニーの設計からキーワード、コンテンツ制作、構造化データなどのテクニカル、被リンクやサイテーションの外部施策までが支援の範囲です。

ホワイトペーパーやウェビナーの支援も同じ会社で持つため、AI検索から来た人を資料請求や商談につなげる仕組みまでまとめて見直したい会社に向いています。

依頼する前に社内で整えること

どの会社に依頼する場合も、次の4つを用意しておくと、最初の提案が自社の営業の流れに合ったものになります。

  1. 商談で実際に聞かれた質問。 営業が受けた質問と、比べられた競合の名前。狙う質問を決める材料になります
  2. 公開してよい情報の範囲。 料金の決まり方、セキュリティの対応、連携先、導入事例の社名のうち、どこまでページに書けるか
  3. 問い合わせの計測方法。 フォームの知ったきっかけにAIを追加できるか、有効なリードと商談を何で計測するか
  4. 1件の価値。 受注単価と、問い合わせから受注までの割合。支援にかけてよい月額の上限が見えます

社内の体制と進め方の順番は、AI検索対策の始め方の記事でも段階ごとに解説しています。

よくある質問

BtoBのLLMO対策は何から始めればいいですか？

商談で聞かれた質問を集め、その質問をChatGPTやGeminiに入れて、自社と競合がどう紹介されるかを確認するところからです。挙がらない理由が外部の記事にあるのか、自社サイトの情報不足にあるのかで、依頼先の種類が変わります。

ITreviewやBOXILへの掲載も依頼できますか？

andmediaは初期施策としてBOXIL・ITreview・イプロスなどの掲載媒体の洗い出しを行い、エイチリンクは月22万円以上のプランで比較メディアへの掲載交渉を代行します。どの媒体まで誰が動くかはプランで異なるため、掲載営業の担当と対象の媒体を契約前に確認してください。

BtoBのLLMO対策の効果はどのくらいで見えますか？

会社と施策で異なります。IDEATECHは2〜4カ月で変化を確認するケースを想定し、エイチリンクは情報の整備に3ヶ月、回答に反映され始めるまで3〜6ヶ月、安定した推薦まで1年程度を目安にしています。nitoの支援では新しいページが公開3日でAIの回答の引用元に入った例もあります。

LLMO対策会社はAIでの推薦を保証しますか？

保証はされません。andmediaとIDEATECHは公式に成果を保証しないと書き、エイチリンクも必ず成果を約束することはできないとしています。推薦を約束する提案には何を根拠にしているかを確認してください。

SEO会社に頼んでいてもLLMO対策は別に頼めますか？

頼めます。LANYはSEOを他社に依頼中でも並行して進められるとし、施策の重なりを避ける体制を提案すると書いています。今の契約でどこまで対応できるかを先に確認し、足りない範囲だけを追加すると重複を防げます。

従業員の少ないBtoB企業でも依頼できますか？

エイチリンクは従業員10名以下のBtoB中小企業向けで、初期費用は0円、最低契約期間もありません。andmediaの公式には、顧客単価10万円以上のBtoB商材に向くとの記載があります。先に、依頼先の対象と契約期間を確認しておくと安心です。

比較サイトに載っていればLLMO対策は不要ですか？

比較サイトに載っていても、その説明が古い料金のままだったり、強みが伝わらなかったりすると、AIの回答もその内容になりやすくなります。比較サイトの掲載情報を最新にしたうえで、料金の決まり方や導入事例を自社のページにも書いておく必要があります。
