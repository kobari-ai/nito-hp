【2026年9月】Claudeにログインできない原因と対処を解説｜メールが届かない・Google・Apple・電話番号

執筆 岡村 希一（nito代表）

Claudeにはパスワードがありません。Anthropicのヘルプ「Claudeアカウントにログインする」によると、ログインはGoogleのアカウントで続けるか、メールに届くログインリンクを使う形で、専用のパスワードを作ることはできないとされています。

そのため、ログインできないときはパスワードの再設定ではなく、ログインメールの受信箱と、登録したときのメールアドレスから確かめます。2026年9月26日のスマホのログイン画面には「Googleで続ける」「Appleで続ける」「メールで続ける」の3つが並んでいました。この記事ではAnthropicのヘルプと実際の画面をもとに、ログインできない原因と対処を整理します。

この記事のポイント
  • Claudeにはパスワードが無い。ログインはGoogle・Apple・メールのリンクのどれか
  • メールが届かないときは@mail.anthropic.comからのメールを迷惑メールと隔離の中から探す。会社や学校のメールはIT部門の設定で止まることがある
  • 別の端末でリンクを開くと検証コードが出る。そのコードは、ログインメールを頼んだ元の端末に入れる
  • Googleで続けられないときは、Googleアカウントの接続から「Claude by Anthropic」を外してからやり直す
  • 新しく作るときは電話番号の確認が必要。同じ番号で確認できるアカウントは3つまで

ログインできない5つの原因

Anthropicのヘルプのトラブルシューティングとよくある質問、「電話番号を確認する」のヘルプを合わせると、原因はおおむね5つに分かれます。

原因 起きること 対処
ログインメールが届かない 件名「Claude.aiへのセキュアログインリンク」のメールが来ない 迷惑メールと隔離を確認し、数分後に再度試す
別の端末でリンクを開いた ログインせずに検証コードが出る コードを元の端末に入れる
登録と違うメールアドレスで入った 別のアカウントに入る、または新しく作る画面になる いつもログインに使っているメールアドレスで入り直す
Googleの接続の問題 Googleで続けるが進まない Googleアカウントの接続を外してやり直す
電話番号の確認 確認コードが来ない、番号が使えない 別の番号を使う、時間をおいて再度試す

原因の見当がつかないときは、先にClaudeのステータスページで障害が出ていないかを見てください。ヘルプも、システム全体の障害が出ているなら、ほかの対処を試す前に復旧を待つよう勧めています。

ログイン画面の3つの入り口

Claudeのログイン画面を開くと、入り口が3つ並びます。ヘルプの本文は「Googleで続行」と「メールで続行」の2つを案内していますが、2026年9月26日のスマホのブラウザでは「Appleで続ける」も表示されていました。ヘルプのよくある質問には、Appleで登録した場合の手順があります。

ヘルプの案内どおり、別の端末でも、いつもログインに使っているのと同じメールアドレスで入るのが確実です。Appleの非公開メールで登録したなら、そのアドレスは @privaterelay.appleid.com で終わるものです。

ログインメールが届かないとき

メールで続けると、件名「Claude.aiへのセキュアログインリンク」のメールが届きます。届かないときにヘルプが挙げている確認は次の4つです。

  1. @mail.anthropic.com からのメールを、迷惑メールのフォルダで探す
  2. 会社のメールなら、サーバーで隔離されたメールを確認する
  3. メールの設定で @mail.anthropic.com を受信を許可する差出人に登録する
  4. 数分おいてから、もう一度ログインを試す

ヘルプの注記では、会社や政府機関、.edu のメールアドレスを使っている人は、メールのセキュリティ設定を変えるためにIT部門への連絡が必要な場合があるとされています。個人のGmailでは届くのに会社のメールでは届かないなら、受信側で止められている可能性があります。

別の端末でリンクを開いたとき

パソコンでログインメールを頼み、スマホでメールのリンクを押した場合は、そのままログインにはなりません。ヘルプによると、別の端末でリンクを押すと検証コードが表示されます。

コードを入れるのは、ログインメールを頼んだ元の端末です。パソコンで頼んだなら、パソコンのログイン画面に戻ってコードを入れてください。

Googleで続けられないとき

Googleで続けるでうまく入れない場合は、GoogleアカウントとClaudeの接続を一度外してからやり直します。ヘルプの手順は次のとおりです。

  1. Googleアカウントの接続のページを開く
  2. 一覧から「Claude by Anthropic」を選ぶ
  3. 「詳細を表示」から「Googleでサインインを停止」を押す
  4. もう一度、Claudeのログイン画面で「Googleで続ける」を選ぶ

Googleでのログインをやめてメールのリンクだけで入りたい人も、同じ手順で接続を外します。

Appleの非公開メールで登録したとき

iPhoneでAppleのアカウントを使って登録するとき、「メールを非公開」を選ぶと、Claudeには @privaterelay.appleid.com で終わる転送用のアドレスが登録される仕組みです。別の端末からログインするときは、この転送用のアドレスを入力して「メールで続ける」を選びます。

ログインのリンクは転送用のアドレスあてに送られ、Apple IDのメールに届きます。ヘルプによると、iPhoneのClaudeアプリで右上のイニシャルを押し、設定の下に表示されるメールアドレスが、その転送用のアドレスです。

電話番号の確認で止まるとき

Claudeのアカウントを初めて作るときは、電話番号にテキストメッセージで届く6桁のコードを入れる確認があります。電話番号を確認するのヘルプでは、この確認はすべての新しい利用者に必要で、飛ばす方法は無いとされています。

起きること 原因と対処
コードが届かない 数分待つ。5分以上なら「もう一度試す」で番号を入れ直す
番号が使えない VoIPの番号、Google Voice、アプリで作った番号、固定電話は使えない
番号が何度も使われたと出る その番号で確認済みのアカウントがすでに3つある。別の番号を使うか、確認済みのアカウントからサポートに連絡して番号のひも付けを外してもらう
コードが効かない 最新のコードを入れる。古いコードは使えない

確認に使った電話番号はあとから変えられません。長く使う番号で確認してください。

よくある質問

Claudeのパスワードを忘れたときはどうしますか？

Claudeにはパスワードがありません。Anthropicのヘルプでも、専用のパスワードは作れないとされています。Google、Apple、メールのリンクのうち、登録したときと同じ方法で入ってください。

Claudeのログインメールが届かないのはなぜですか？

迷惑メールのフォルダに入っているか、会社や学校のメールのサーバーで止まっている可能性があります。@mail.anthropic.com を受信を許可する差出人に登録し、数分おいてから試してください。

Claudeで検証コードが表示されたのはなぜですか？

ログインメールを頼んだ端末とは別の端末でリンクを押したためです。表示されたコードはログインメールを頼んだ元の端末に入力します。

ClaudeにGoogleでログインできないのはなぜですか？

GoogleアカウントとClaudeの接続に問題がある可能性があります。Googleアカウントの接続のページで「Claude by Anthropic」のサインインを停止してから、もう一度Googleで続けるを選んでください。

Appleで作ったアカウントに別の端末から入るには？

Appleで「メールを非公開」を選んで登録した場合は、@privaterelay.appleid.com のアドレスを入力して「メールで続ける」を選びます。リンクはApple IDのメールに届きます。

Claudeの電話番号の確認をスキップできますか？

できません。すべての新しい利用者に電話番号の確認が必要で、テキストメッセージを受け取れる番号が要ります。

Claudeを別の端末で使うにはどうしますか？

いつもログインに使っているのと同じメールアドレスを入れて入ります。ヘルプもこの方法を案内しています。Googleで登録したなら、別の端末でも同じGoogleのアカウントで続けてください。

Claudeで複数のアカウントを切り替えるには？

同じメールアドレスに個人のアカウントとTeamやEnterpriseのアカウントがあるなら、左下のイニシャルを押して、使いたいアカウントを選びます。チェックマークが付いているのが今のアカウントです。
