n8nの料金は3つに分かれる

n8nは画面でノードをつないでワークフローやAIエージェントを組む自動化の道具です。ソースはGitHubのリポジトリで公開されていて、スターは約20万9千あります。作り方の選び方は「AIエージェントの作り方」のノーコードの節で扱いました。

会社でn8nを使うときの費用は次の3つです。

費用 中身 払う先
n8nの利用料 クラウド版の月額か、セルフホストのBusiness・Enterpriseのライセンス n8n
AIのモデルの代金 OpenAI・Anthropic・Googleなどのモデルを呼ぶ代金 各モデルの提供元か、n8nのGatewayクレジット
サーバーと人手 セルフホストのサーバー・更新・バックアップ・守り 自社とクラウド事業者

料金ページの金額は1つ目だけで、AIを呼ぶワークフローなら2つ目が、セルフホストなら3つ目が加わります。

実行回数の数え方と見積もり

料金ページのよくある質問は、実行を「ワークフロー全体の1回の実行」と定めています。ステップがいくつあっても、扱うデータが多くても、ワークフロー1回の実行は1回です。 他社の道具が数えるオペレーションやタスクとの違いとして、n8nが前に出している点です。

実行の数え方の説明によると、回数に入るのはトリガーやスケジュールで自動で動いた本番の実行だけです。エディターでの手動のテスト、サブワークフロー、エラー時のワークフロー、新しいデータが無かったポーリング、始まる前に失敗したWebhookは数えません。スケジュールで動いた実行は失敗しても1回です。

AIエージェントでは数え方に注意が要ります。料金ページはエージェントの会話の1ターンを1回の実行と数えると書き、忙しいチャットのエージェントは同時実行の上限に先に当たるとしています。

見積もりの例として、よくある質問は次の数え方を挙げています。

  • 決まった時刻に動くワークフロー：毎日1回なら月30〜31回、5分ごとなら月約8,600〜8,900回
  • Webhookで動くワークフロー：きっかけになる出来事が1日に起きる数が、1日の実行回数
  • チャットボット：週の会話の数に、1会話あたりのメッセージの数を掛ける

この数え方で試算すると、社員50人が社内の問い合わせに答えるエージェントに1日5回ずつ聞き、月20日使えば月5,000回です。毎朝1回の集計を10本足すと月300回、1日100件届く問い合わせフォームの処理を足すと月約3,000回が加わります。合計の約8,300回なら、月1万回のProに収まる計算です（試算です）。

回数のほかに同時実行の上限もあります。同時実行の説明によると、上限はWebhookやトリガーから始まる本番の実行だけにかかり、超えた分は待ち行列に入って古い順に処理されます。手動のテスト、サブワークフロー、エラー時のワークフローは数えません。1回の実行の上限時間はStarterが5分で、待ちのノードや人の承認を待つ時間は数えない決まりです。

StarterとProは超過料金の欄が「Capped」で、超えた分は請求されない仕組みです。上限に達した後にワークフローがどう扱われるかは料金ページに書かれていません。使った回数は分析の画面（Insights）で見られます。

n8nのBusinessプランの料金と超過料金

BusinessはSSO・LDAP、6つの共有プロジェクト、開発と本番を分ける環境、Gitでの版の管理が付くプランです。動かせるのはセルフホストだけで、年8,000ユーロ（約141万円）で月4万回、月払いなら800ユーロです。サポートはフォーラムだけで、担当者のつくサポートはEnterpriseに限られます。

回数を増やす段も料金ページに載っていて、年払いで5万回は年9,852ユーロ、10万回は年17,260ユーロ、50万回は年52,450ユーロです。上限を超えてもワークフローは止まらず、上の段に上げなければ超過料金がかかることがあると、よくある質問は答えています。上限が近づくと営業から連絡があり、年払いのBusinessは年間の量の80%に近づいた時点で連絡が来ます。

Businessの超過料金は上限を超えた分30万回ごとに4,000ユーロ（4,800ドル）です。料金ページはこの値を2026年10月26日からの価格として載せています。1回あたりに直すと約2.3円で、4万回の段を年払いしたときの1回あたり約2.9円を下回ります。

ライセンスキーは何台のインスタンスにも入れられ、回数は全台の合計で数えます。キーは毎日n8nのライセンスサーバーと通信して実行回数などを送るため、社外への通信を絞っている会社はライセンスの管理のとおりCloudflareのIPの範囲を許可します。社外と通信できない環境向けには、n8nが発行する通信の要らないライセンス証明書を環境変数（N8N_LICENSE_CERT）で入れる方法も同じページに載っています。

従業員20人未満で、調達額の合計が500万ユーロ未満などの条件を満たす会社は、StartupプランでBusinessが半額になり、年払いで月333ユーロ（約5万9千円）です。

月払いの解約はその請求期間の終わりに、年払いは年の終わりに効き、日割りの返金はありません。

セルフホストにかかる費用

n8nを使う形の選び方は、自社のサーバーで動かすCommunity版を、ほぼ全部の機能が無料で使える版と説明しています。メールアドレスを登録すると、フォルダー・過去の実行を編集画面で再現する機能・実行に独自のデータを付ける機能も無料で加わります。

ただし版ごとの違いを読むと、会社で使うときに要る機能がCommunity版には入っていません。

  • ワークフローと認証情報の共有（開けるのはインスタンスのオーナーと作った人だけ）
  • プロジェクトでの分け方
  • SSO（SAML・LDAP）
  • 開発と本番の環境の分離と、Gitでの版の管理
  • 外部の秘密情報の保管庫との連携と、ログの外部への送信

ライセンス料が0円でも、複数人で同じワークフローを直す運用になった時点でBusinessの費用がかかります（クラウド版ならStarterから共有できます）。1人か2人が作って全社で結果を使う形なら、Community版のまま回せることもあります。

起動そのものは短く、Dockerでのインストールの説明の例からタイムゾーンなどの設定を省くと次の2行です。

docker volume create n8n_data
docker run -it --rm --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n n8nio/n8n

既定のデータベースはSQLiteで、PostgreSQLへの切り替えにも対応しています。同じページはサーバーとコンテナの設定・資源の増やし方・守り・n8nの設定の知識が要るとし、セルフホストは慣れた人に勧めると書いています。設定を誤るとデータの消失やセキュリティの問題、停止につながるという注意も添えられていました。

ライセンス料の代わりに、自社で持つ費用は次の4つです。

費用 中身
サーバー 仮想マシンと保存領域、PostgreSQLを使うならデータベース
更新の人手 新しい版への更新。安定版の最新は2026年10月29日の2.45.6
守りの人手 外から届く入口の守り・認証・バックアップと戻す手順の確認
モデルの代金 Gatewayクレジットは使えないので、自社で契約したキーで払う

セルフホストが向くのはデータを自社の環境から出せない決まりがあり、サーバーの面倒を見る人がいる会社です。クラウド版でもよいなら、更新と守りの人手が消える分を月額と比べて決めます。

n8nのライセンスで許されること

Community版のライセンスは、n8nが2022年に作ったSustainable Use Licenseです。GitHubのLICENSEの制限は次の3つです。

  • 自社の内部の業務か、非商用・個人の用途に限って使い、手を加えられる
  • 他人に配ったり渡したりできるのは、非商用の目的で無料で行う場合だけ
  • ライセンスや著作権の表示を消したり、変えたり、隠したりできない

ファイル名に「.ee.」が入るソースは別のEnterpriseのライセンスで、キーが要る機能に当たります。

ライセンスのよくある質問は、自社の人だけがワークフローを作ったり直したりするなら、無料で使えると書いています。会社の使い方に当てはめると次のとおりです。

使い方 ライセンスのよくある質問での扱い
社内の業務の自動化に使う できる
顧客のための自動化を自社のインスタンスで作る（顧客は作れず直せない） できる
ワークフローの作成・保守・研修・コンサルの料金を取る できる
自社製品の裏側で使い、利用者は作られた自動化を動かすだけ できる
n8nをサービスとして置き、顧客にワークフローを作らせる できない
外部の利用者が独自の画面・API・MCP・AIエージェント経由で自分のワークフローを作る できない
ロゴを外して、n8nをそのまま自社の名前で出す できない

画面を自社のものに替えても、外部の利用者がワークフローの中身を決められるなら認められない、という例も同じページに載っています。利用者がワークフローを組める機能を製品に入れたい場合は営業（sales@n8n.io）にEnterpriseのライセンスを相談する形です。

このよくある質問はセルフホストの話で、n8nのクラウドは別の利用規約に従います。表は文言を読んだもので法的な判断ではないため、迷う使い方はlicense@n8n.ioに書面で確かめておくと後で揉めません。

AIを呼ぶ代金は別にかかる

n8nの料金に含まれるのは実行の回数で、ワークフローの中でAIのモデルを呼ぶ代金は別です。払い方は2通りあります。

1つはn8nのGatewayクレジットです。クラウド版のStarterとProで使え、OpenAI・Anthropic・Google Geminiのモデルや、Web検索などの外部のサービスを、各社のアカウントやAPIキーなしで呼べます。前払いの残高から使った分が引かれ、単価はn8nのサービスの料金ページに載っています。残高が0になると、Gatewayクレジットを使うノードは止まります。買い足したクレジットは12か月で失効し、使い残しは返金されません。 EnterpriseとセルフホストではGatewayクレジットは使えません。

もう1つは自社で契約したモデルのAPIキーを登録する方法です。請求は各社から届き、データの扱いもその会社との契約で決まります。

これとは別に、ワークフローを作るのを手伝うAssistant（プレビュー）のクレジットが、Starterに月1,600、Proに月4,000か9,600付きます。毎月戻り、繰り越しはできない決まりです。モデルの代金の見積もり方は「Difyの料金」のAPI代の節と同じ掛け算で出せます。エージェントは1ターンの中でモデルを何回も呼ぶことがあるため、試作で提供元の管理画面の数字を見てから掛け算すると外れにくくなります。

DifyやZapierとの料金の違い

同じように業務を自動化する道具でも、料金を数える単位はそれぞれ別です。

製品 数える単位 入り口の料金
n8n ワークフロー1回の実行（ステップの数は数えない） Starterが年払いで月20ユーロ・2,500回
Dify ワークスペースごとの月額と、付いてくるクレジット Professionalが月59ドル
Zapier 成功したステップ1つで1タスク（トリガーは数えない） Professionalが年払いで月19.99ドル・750タスク
Make ほとんどのアクションが1クレジット（データの読み込みも数える） クレジットの量で段がある
Copilot Studio Copilotクレジット 1パック月29,985円で25,000クレジット

Zapierの料金ページはタスクを、成功した1つの作業ごとに数えます。Makeの料金ページは1回の実行で2から数千のクレジットを使うことがあるとしています。ステップの多いワークフローほど、ステップ数で値段が変わらないn8nは見積もりを立てやすくなります。 1ドル158.06円（2026年10月29日のユーロ円とユーロドルから算出）で換算すると、DifyのProfessionalは月約9,300円、ZapierのProfessionalは月約3,200円です。

チャットの会話が多い用途ではn8nの回数が先に増えるため、Difyとは両方の数え方で見積もって比べます。細部は「Difyの料金」と「Copilot Studioの料金」にまとめました。

n8nを入れる前に会社が決めること

プランの差は月額より上限の差です。次の4つを決めると、候補が1つか2つに絞れます。

  • 月に何回動かすか：ワークフローごとに回数を数えて足す。チャットのエージェントはメッセージの数で数える
  • データを社外に出せるか：n8nのクラウドのデータはフランクフルトに置かれる。出せないならセルフホスト
  • SSOが要るか：SSOでログインさせるならBusiness（セルフホスト）かEnterprise。複数人で同じワークフローや認証情報を使うだけなら、クラウド版のStarter（共有プロジェクト1つ）とPro（3つ）でもできる。セルフホストのCommunity版ではできない
  • 保守を誰が持つか：セルフホストの更新・守り・バックアップを担う人がいなければ、クラウド版

もう1つ、顧客に渡す仕組みにn8nを使うなら、ライセンスの表で外部の人がワークフローを作れる形になっていないかを先に確かめます。そこに当たるなら、プランの比較より前にEnterpriseの相談が要るためです。

よくある質問

金額はすべて2026年10月30日に見た公式ページの表示です。

n8nは無料で使えますか？

自社のサーバーで動かすCommunity版は無料で、実行回数の上限もありません。n8nのクラウドは14日間の無料試用のあと有料のプランになります。

n8nの料金は1人いくらですか？

1人ごとの料金はありません。どのプランもユーザーの数は無制限で、月の実行回数で値段が決まります。

n8nのStarterとProの違いは？

年払いで月20ユーロと月50ユーロで、実行回数は月2,500回と1万回です。Proは同時実行が20に増え、実行の記録を30日残せて、管理者のロールが付きます。

n8nの実行回数を超えるとどうなりますか？

BusinessとEnterpriseはワークフローが止まらず、上の段に上げなければ超過料金がかかることがあります。StarterとProは超過料金がなく、上限に達した後の動きは料金ページに書かれていません。

n8nのBusinessプランはクラウドで使えますか？

今は使えません。Businessはセルフホストだけで、クラウドで使えるようにする待ちリストがあります。

n8nは請求書払いできますか？

年払いのBusinessとEnterpriseは請求書と銀行振込で払えます。StarterとProは比較表では請求書払いがありません。

n8nを商用利用できますか？

社内の業務に使う、顧客のための自動化を作って料金を取る、といった使い方はCommunity版で認められています。顧客が自分でワークフローを作れる形で提供するには、n8nとの別の契約が要ります。

n8nのクラウド版のデータはどこに保存されますか？

ドイツのフランクフルトのサーバーで、EUの中に置かれます。セルフホストなら自社が選んだ場所です。
