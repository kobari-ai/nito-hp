「接続が途切れました。回答全体の受信を待っています」は、ChatGPTが回答の流れを回復しようとしているときに出る表示です。OpenAIのサポートは2026年10月、外部のツールとつないで長い作業をさせていた人の報告に、この表示が出ても処理が止まったとは限らないと答えています。まずは30〜60秒待ち、出ている回答をコピーしてから再読み込みするのがおすすめです。

長い文章が途中で終わるのは別の止まり方で、2026年10月13日に試したときは同じチャットで「続けて」と送ると続きが出ました。この記事では止まり方を5つに分け、試すことをヘルプとコミュニティの報告、試した結果で整理します。

:::takeaways
- 「接続が途切れました」は**つなぎ直している最中の表示**。30〜60秒待ち、回答をコピーしてから再読み込み
- 長い文章が途中で終わったら、**同じチャットで「続けて」と送る**
- 書き終えた回答に「続けて」と送ると、**最初から書き直しが始まることがある**
- 続けるボタンは**ログインせずに試した画面では出なかった**
- 考え中のまま進まないときは、**30〜60秒待ってから生成を停止して再生成**
:::

## ChatGPTが途中で止まる5つの症状

文字が出ている途中で止まったのか、何も出ないまま考え中が続いているのかで、試すことは変わります。

| 症状 | 画面で起きていること | 最初に試すこと |
|---|---|---|
| 接続が途切れましたと出る | 回答の途中でこの文言が出る | 30〜60秒待ち、コピーしてから再読み込み |
| 長い文章が切れる | 文の途中や区切りのいい所で終わる | 同じチャットで「続けて」と送る |
| 続けるボタンがない | 解説記事にあるボタンが無い | ボタンを探さずに「続けて」と送る |
| 考え中のまま止まる | Thinking…の表示のまま進まない | 30〜60秒待ち、生成を停止して再生成 |
| ほかのエラーで止まる | 別のエラーの文言が出る | 文言を読み、再生成か再読み込み |

## 接続が途切れました。回答全体の受信を待っていますと出たら

OpenAIのヘルプのエラーの一覧には、2026年11月1日の時点でもこの文言の説明はありません。説明はOpenAIのコミュニティにあり、10月17日（日本時間）にOpenAIのサポートが答えています。**この表示が出ても止まったとは限らず、つなぎ直している最中のことがあります。慌てて再読み込みすると、途中の回答を失うことがあります。**

### 表示の意味と文言

サポートの返答は自作のMCPコネクタで長い作業をさせていた人の報告に付いたものです。この表示はChatGPTがブラウザへの応答の流れを回復しようとしているときに出るもので、実行が止まったとは限らないと説明しています。ただし報告した人は本当に止まった回もあったと書いていて、待っても変わらなければ次の手に進みます。

日本語の画面ではこの文で出るという利用者の投稿が2026年10月にあり、英語の画面では「Connection interrupted. Waiting for the complete answer」と出ます。2026年1〜4月ごろは「ストリーミングが中断されました。完全なメッセージを待機しています」という別の文言で報告されていて、変わった日付は公式に出ていません。**古い文言の解説が検索で出てきても、試すことは下の順番と同じです。**

### 報告されている場面

OpenAIのコミュニティに出ている報告を、場面ごとに並べます。

- **画像の生成**：2026年6月の投稿。この表示か画像の生成の失敗が3割ほど出た。投稿者は5.5 Instantで作ったときだけのようだと追記し、9月にOpenAIのサポートが、エラーの文言と使ったモデル、時刻をサポートへ個別に送るよう返信
- **自作のMCPコネクタの長い作業**：2026年10月の投稿。上のサポートの説明はこの投稿への返答
- **iPhoneのアプリの長い作業**：2026年10月18日（日本時間）の投稿。停止ボタンや進み具合の表示が消える
- **GPT-6の思考の強さがExtra High**：2026年10月22日の投稿。思考の途中で止まり、送り直すと「Connection interrupted」にあたる表示が出た（投稿者がアプリの表示を英語に訳したもの）

4つとも1回の回答に時間がかかる作業の途中で出ています。10月7日には会話の読み込みの失敗や「Resume stream unavailable」と並べてこの表示を挙げたスレッドが立ち、書き込みは37件まで増えました。スレッドにOpenAIのサポートの返答は無く、コミュニティのモデレーターがステータスページで障害を確かめるよう返信しています。**原因は場面から決めつけず、下の順番で試すのがおすすめです。**

### 試す順番

上から順に試し、直ったところで止めます。

1. 30〜60秒待つ。表示が出ても回答は続いていることがある
2. 出ている回答と自分の入力をコピーしておく
3. ページを再読み込みする（ハード更新は Cmd またはCtrlとShiftとR）
4. 新しいチャットで送り直す
5. [ステータスページ](https://status.openai.com/)で障害を確かめる
6. 会社の回線でだけ出るなら、WebSocket（wss://ws.chatgpt.com）を通しているかを情シスに確かめる

2は画像の生成の投稿者が読み込み直したら「Too many requests」と出て会話を失ったと書いているためです。ステータスページの履歴では、2026年10月に会話に影響した障害が5日（日本時間で6日・8日・10日・21日・22日）あり、22日の障害は日本・インド・韓国の利用者に影響していました。

6はネットワークの推奨のヘルプによるもので、WebSocketの通信を組織が止めていると一部の機能が止まったり切れたりすると書かれています。**会社でだけ出るなら、ブラウザより先に社内の通信設定を確かめるのがおすすめです。**回線まわりのほかの表示は[ChatGPTのネットワーク構成の問題とClientError](/media/chatgpt-network-error/)にまとめています。

## 長い文章が途中で切れるとき

OpenAIのヘルプにはChatGPTが1回の回答で書ける長さの数字は載っていません。手がかりになるのは2023年5月12日のリリースノートで、上限のトークン数を超えて続きを生成できるようになったと書かれています。**2023年の時点で、1回の回答に長さの上限があったことがこの記述から分かります。** 今の上限の数字や、何字で切れるかは公開されていません。

試したときは47都道府県を1県600字ずつ（合わせて約2万8,000字）頼んだ1回目の回答が、群馬県まで書いたところで終わりました。最後の行は「次の範囲は11. 埼玉県から20. 長野県までです」で、文が途中で切れたのではなく、ChatGPTが自分で区切りを入れて止めていました。3回目は福島県までの7道県（約4,600字）で「第1部は以上です」と区切り、2回目は47都道府県を1回で書き切っています（約3万1,000字）。**同じ頼み方でも、区切るかどうかと区切る位置は毎回違いました。**

### 続けてと送る

区切られた回答の続きは同じチャットで「続けて」と送れば出ます。**試したときは1回目が埼玉県から長野県までの10県（約5,700字）、3回目が茨城県から愛知県までの16県（約1万字）で、どちらも区切った所の次から始まりました。**最後にはまた「次は三重県から」のように次の範囲が書かれていて、47都道府県をそろえるには何回か送ることになります。

送る前に、回答の最後の行を見てください。2回目の試しでは47都道府県を書き終えて「以上が、北海道から沖縄県までの47都道府県です」と締めた回答に「続けて」と送っています。するとChatGPTは「抜けていた北海道から愛知県までの23道県」を補うと書き、北海道から書き直し始めました。**最後が締めの文なら続きは無いので、「続けて」は送らないほうが無駄がありません。**

### 最初から分けて頼む

長い文章が要るなら、最初から1回の範囲を決めて頼む手もあります（この頼み方は試していません）。「北海道から群馬県までの10道県を、1県600字で」のように範囲を書き、終わったら次の範囲を頼むと、どこまで書き終えたかを自分で追えます。報告書や小説なら章ごと、コードならファイルや関数ごとが区切りの目安です。

## 続けるボタンが出ないとき

解説記事に「Continue generating」として出てくるボタンのもとは、上で触れた2023年5月のリリースノートの項目です。2024年3月にはOpenAIのコミュニティでボタンが消えた・戻ったという投稿が続き、2026年10月30日にも「続けるボタンは無いようだ」という投稿があります。外したという公式の告知は見つかりません。

2026年10月13日にログインせずスマホ幅で試したときは、3回とも**回答の下にあったのはコピーと共有のボタンだけ**でした。自分で区切った回答だったので上限で切れたときだけ出る可能性もあり、ログインした画面とアプリでは確かめていません。**ボタンが無くても、同じチャットで「続けて」と送れば続きは出ました。**

### 考えながら答え始めるGPT-6

2026年10月7日のリリースノートによると、GPT-6は考えたりツールを使ったりしながら答え始め、追加の指示なしで見つけたことを書き足します。

**止まったように見えても、まだ書き足している途中のことがあります。** 試したときは書いている間、入力欄の右に「生成を中止」のボタンが出ていて、このボタンが出ている間は回答はまだ終わっていません。

## 考え中のまま止まるとき

何も書かれないまま「Thinking…」「Generating…」の表示が続くときについて、OpenAIのヘルプは試す順番を示しています。上から順に試し、直ったところで止めます。

1. 回答が終わるか30〜60秒待つ
2. 生成を停止してから再生成する
3. 新しいチャットで送り直す
4. ハード更新（Cmd またはCtrlとShiftとR）か、デスクトップアプリの再読み込み
5. サインアウトして入り直す
6. 拡張機能を止めたシークレットウィンドウで開く
7. VPN・プロキシ・セキュアDNSを切る
8. 別のブラウザ・回線・端末で試す
9. [ステータスページ](https://status.openai.com/)で障害を確かめる

ヘルプは会話が長いときにも新しいチャットを勧めています。**同じ会話だけで止まるなら3を、どの会話でも止まるなら9と8を先に試すのがおすすめです。**手順の詳しい説明は[ChatGPTのエラーメッセージ一覧](/media/chatgpt-error-messages/)にまとめています。

### Stopped thinkingと出て止まるとき

2026年10月20日以降、OpenAIのコミュニティには、GPT-6で長く考えさせたときに答えが出ないまま止まるという報告が続いています。思考の強さをExtra Highにした人が多く、Highに下げても出たという書き込みもあります。画面に「Stopped thinking」と出る、停止ボタンが消えて入力欄が待機に戻る、という書き込みもあり、公式の返答はまだありません。**上の手順で直らなくても、自分の端末や回線のせいとは限りません。**毎回遅いだけなら[ChatGPTが重い・遅いとき](/media/chatgpt-slow/)が近い症状です。

## エラーで止まるとき

回答の途中でエラーの文言が出たら、文言で見分けます。ヘルプに載っている文言のほかに、コミュニティで報告が続いている文言もありました。

| 文言 | 載っている所 | 試すこと |
|---|---|---|
| 応答の生成中にエラーが発生しました | ヘルプ | 再生成を押す。続くならブラウザか端末を再起動 |
| 接続が途切れました。回答全体の受信を待っています | コミュニティ | 上の節の順番で試す |
| この回答を読み込めませんでした | 説明が見つからない | 回答をコピーしてから再読み込み |
| Error in message stream | コミュニティ | ヘルプの止まったときの手順を試す |
| ネットワークエラーが発生しました | ヘルプ | VPNやプロキシを切り、別の回線で試す |
| 上限に達しました | モデルのヘルプ | リセットの時刻まで待つ |

**説明の無い文言でも、再読み込みの前に回答をコピーしておけば、会話が開けなくなっても中身は手元に残ります。**上限の種類とリセットの時刻は[ChatGPTで上限に達したとき](/media/chatgpt-limit-reached/)で詳しく扱っています。

### Error in message streamと出たとき

2026年9月23日のコミュニティの投稿は、Androidのアプリでファイルを添付した長い会話が「Thinking」のあと止まり、この表示が出たという報告です。ウェブ版で出たという返信もあり、書き込みは14件まで増えましたが公式の返答はありません。

どの症状でも直らないときは、ヘルプのとおりタイムスタンプ付きのHARファイルとブラウザのコンソールのエラーを集め、使ったモデルと会話のURLかIDを添えてサポートに問い合わせます。

## まとめ

状況ごとに最初に試すことは次のとおりです。

- **接続が途切れましたと出た場合**：30〜60秒待ち、回答と入力をコピーしてから再読み込み
- **長い文章が途中で終わった場合**：同じチャットで「続けて」と送る
- **書き終えた回答に続きを頼みたい場合**：「続けて」でなく、足したい範囲を書いて頼む
- **考え中のまま進まない場合**：ヘルプの順番どおり待ってから生成を停止して再生成
- **何度やっても止まる場合**：ステータスページと別の回線で比べる。会社でだけならWebSocketを確かめる

## よくある質問

### ChatGPTの回答が途中で止まるのはなぜですか？

文の途中で切れる原因の1つとして、OpenAIは2023年に1回の回答の上限を挙げていました。今の上限の数字は公開されていません。試したときは文の途中では切れず、ChatGPTが自分で区切りを入れて終えました。何も出ないまま止まるときは、ヘルプの手順を上から試します。

### ChatGPTに続きを書いてもらうにはどうすればいいですか？

同じチャットで「続けて」と送ります。試したときは区切った範囲の次から続きが出ました。回答の最後が締めの文なら続きは無いので、送る前に最後の行を見てください。

### ChatGPTの続けるボタンは無くなったのですか？

外したという公式の告知は見つかりません。2026年10月13日にログインせずに試した画面では、回答の下にコピーと共有のボタンしかありませんでした。ログインした画面とアプリは確かめていません。

### ChatGPTは有料版なら途中で止まりませんか？

プランごとの1回の回答の長さは、ヘルプに書かれていません。この記事の実測はログインしていない画面だけで、有料版では試していません。長い文章はプランにかかわらず、範囲を分けて頼むとどこまで書いたかを追えます。

### ChatGPTのコードが途中で止まるときはどうしますか？

同じチャットで「続けて」と送れば続きは出ますが、2024年9月のコミュニティの報告ではコードの書式が崩れることがありました。ファイルや関数ごとに分けて頼むと、どこまで書いたかを追えます。

### ChatGPTが考え中のまま止まったら何秒待てばいいですか？

ヘルプは30〜60秒としています。それでも終わらなければ、生成を停止してから再生成し、次に新しいチャットで送り直します。

### ChatGPTの接続が途切れましたとはどういう意味ですか？

ChatGPTがブラウザへの応答の流れを回復しようとしているときの表示です。2026年10月にOpenAIのサポートがコミュニティで、外部のツールとつないだ長い作業の報告に対し、この表示が出ても処理が止まったとは限らないと答えています。

### ChatGPTで接続が途切れましたと出たらどうしますか？

まず30〜60秒待ちます。変わらなければ出ている回答と入力をコピーしてから再読み込みし、直らなければ新しいチャットで送り直すのがおすすめです。あわせてステータスページで障害が出ていないかも確かめてください。

### ChatGPTが繰り返し止まるのはなぜですか？

同じ会話でだけ止まるなら、会話が長くなっていることを疑います。ヘルプも長い会話では新しいチャットを始めるよう書いています。どの会話でも止まるなら、ステータスページで障害を確かめ、別の回線やブラウザで比べます。
