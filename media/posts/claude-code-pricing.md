Claude Codeは、Anthropicの有料プラン（Pro・Max・Team・Enterprise）に含まれる形か、APIの従量課金のどちらかで使います。無料プランでは使えません。日本向けの料金ページは2026年9月18日時点で消費税込みの表示になっており、Proは月$22（年払いなら月$18）、Maxは月$110からです。

料金そのものより分かりにくいのが、使用量の上限の仕組みと、定額と従量課金の境目です。プランに入っていても環境変数の設定ひとつで従量課金に切り替わり、上限に当たったときの選択肢も3つあります。Anthropicの料金ページ、ヘルプセンター、Claude Codeの公式ドキュメント（いずれも2026年9月18日取得）を一次ソースに、そこまで含めて書きます。

:::takeaways
- **無料プランではClaude Codeは使えない**。Pro（月$22、年払いで月$18）以上か、APIの従量課金
- Maxは**Pro の5倍（$110）か20倍（$220）**の使用量。Teamはスタンダード$27.50・プレミアム$137.50（月払い、1シート）
- 上限は**5時間ごとの枠と1週間の枠の2段構え**で、claude.aiのチャットとClaude Codeが同じ枠を使う
- 上限に当たっても勝手に課金はされない。**待つ・上位プラン・使用クレジット**の3択
- APIはSonnet 5が入力$2・出力$10（100万トークンあたり）。公式の平均は開発者1人あたり1日約$13
:::

## Claude Codeの料金は2通り

Claude CodeはターミナルやVS Codeなどのエディタから使うAnthropicのコーディングエージェントで、料金はclaude.aiのアカウントでログインして**定額プランの枠内で使う**か、APIキーで認証して**使ったトークン量で払う**かの2通りしかありません。

<figure class="post-figure"><img src="/media/images/claude-code-pricing/00_fig_billing.png" alt="Claude Codeの請求は定額（Pro・Max・Team）と従量（API）の2つに分かれる図" loading="lazy"><figcaption>同じClaude Codeでも、ログインの仕方で請求の種類が変わる</figcaption></figure>

どちらで動いているかは、認証の方法で決まります。`claude` を起動して `/login` でclaude.aiのアカウントに入れば定額プラン、環境変数 `ANTHROPIC_API_KEY` が設定されていればAPIキーで認証されて従量課金です。ProやMaxに加入していてもこの環境変数があるとAPIキーが優先される、と公式ヘルプに明記されています。**プランに入ったのにコンソールの残高が減っている**というときは、まずここを疑います。

## プラン別の料金とClaude Codeで使える範囲

日本向けの料金ページ（claude.com/ja/pricing）は「Prices include 10% JCT」と書かれており、米国向けの$20・$100・$200に消費税10%が乗った金額が表示されます。2026年9月18日時点の表示です。

| プラン | 月額（消費税込み） | Claude Code | 使用量の目安 |
|---|---|---|---|
| Free | $0 | **使えない** | 5時間枠あり。日常的な質問向け |
| Pro | $22（年払いは月$18、$220一括） | 使える | Freeの5倍以上 |
| Max 5x | $110 | 使える | Proの5倍 |
| Max 20x | $220（$200＋消費税） | 使える | Proの20倍 |
| Team スタンダード | 1シート$27.50（年払いは$22） | 使える | Proより多い |
| Team プレミアム | 1シート$137.50（年払いは$110） | 使える | スタンダードの5倍 |
| Enterprise | 1シート$20（年払い）＋API単価で使用量 | 使える | 管理者が上限を設定 |

出典はAnthropicの料金ページです。Freeの行にある「使えない」は、機能比較表の「Claude Code」の行がFreeだけ「いいえ」になっていることから取っています。

### Pro（月$22）で使えること

ProはClaude Codeが使える最も安いプランです。Claude Codeのほかに、Claude Design・Slides・Docs、プロジェクト、Claude in Chrome、Microsoft 365向けのClaudeが付きます。使えるモデルはOpus・Sonnet・Haikuで、Fableは「使用クレジット」経由になります。5時間あたりの使用量はFreeの5倍以上と書かれていますが、**固定のメッセージ数は公開されていません**。会話の長さ、選ぶモデル、使う機能で消費が変わるためです。

### Max（$110・$220）で増えるもの

MaxはProの全機能に加えて、使用量がProの5倍か20倍になり、出力の上限が上がり、混雑時の優先アクセスと新機能の早期アクセスが付きます。Fableは週の上限の50%まで使えます。料金ページには「一日中Claudeと仕事をする方へ」とあり、Claude Codeを毎日数時間回す人向けの設計です。

### Team・Enterpriseの単価

Teamは2〜150名向けで、シートが2種類あります。スタンダードは月払い$27.50で使用量がProより多く、プレミアムは$137.50でスタンダードの5倍です。どちらもClaude Codeが含まれ、一元請求・SSO・管理者コントロールが付きます。Enterpriseは1シート$20（年払い）にAPI単価での使用量が加わる形で、管理者がユーザーごとの利用上限を設定できます。

## 使用量の上限の仕組み

料金ページのFAQによると、すべてのプランに**5時間のローリングウィンドウでリセットされる上限**があり、有料プランにはさらに**週次の上限**が加わります。5時間の枠が回復しても、週の枠を使い切っていれば止まります。

<figure class="post-figure"><img src="/media/images/claude-code-pricing/00_fig_limits.png" alt="5時間ごとの枠と1週間の枠の2段構えで、claude.aiのチャットとClaude Codeが同じ枠を使う図" loading="lazy"><figcaption>上限は2段構え。ウェブ・アプリ・Claude Codeの利用がすべて同じ枠から減る</figcaption></figure>

見落としやすいのは、この枠が**ウェブ・デスクトップ・スマホのClaudeとClaude Codeで共通**だという点です。昼間にclaude.aiで長い文章を作らせると、その分だけ夜のClaude Codeの枠が減ります。Claude Codeの公式ドキュメントにも、5時間枠と週枠は「すべてのモデル全体で共有される」ため、`/model` でモデルを切り替えても上限は回復しないと書かれていました。

上限に達すると、Claude Codeには「セッション制限に達しました」か「週間制限に達しました」と出ます。v2.1.234以降はリセットまで自動で待って作業を再開する設定もあり、`/rate-limit-options` から選べます。

Claude Codeの週次の上限は2026年9月14日に見直され、臨時増量の前より25%多く、直前の9月13日までより約17%少ない水準になりました。変更の経緯とリセットの時刻の確かめ方は[Claudeの使用制限とリセット時間の記事](/media/claude-usage-limits/)にまとめています。

## 上限に達したときの3つの選択肢

公式ヘルプが挙げている選択肢は3つです。どれを選んでも、**自動で従量課金に切り替わることはありません**。

1. **リセットを待つ**。5時間枠は時間で回復し、週枠は週の区切りで回復する
2. **上位プランに上げる**。Proで頻繁に当たるならMax 5x、Max 5xで当たるならMax 20x
3. **使用クレジットをオンにする**。プランの枠を超えた分だけ、標準のAPI単価で請求される

3つ目の使用クレジットは、claude.aiの「設定＞使用状況」（Settings > Usage）でオン・オフを切り替え、月間の支出上限も設定できます。Claude Code側からは `/usage-credits` で同じ画面が開く仕組みです。Pro・Maxで支出上限に達すると、Claude Codeが上限を引き上げるか聞いてくるので、CLIを離れずに続けられます。

## API従量課金の料金

APIキーで使う場合はモデルごとの単価に使ったトークン量を掛けた金額が請求されます。2026年9月18日時点の主なモデルの単価（100万トークンあたり）です。

| モデル | 入力 | 出力 | キャッシュ読み取り |
|---|---|---|---|
| Claude Fable 5.1 | $10 | $50 | $0.25 |
| Claude Opus 5 | $5 | $25 | $0.50 |
| Claude Sonnet 5 | $2 | $10 | $0.20 |
| Claude Haiku 4.5 | $1 | $5 | $0.10 |

<figure class="post-figure"><img src="/media/images/claude-code-pricing/cc_05_api_pricing_table.jpg" alt="Anthropic公式ドキュメントのモデル別料金表。Fable 5.1、Opus 5、Sonnet 5、Haiku 4.5の入力・出力・キャッシュ単価" loading="lazy"><figcaption>公式ドキュメントのモデル料金表（2026年9月18日）</figcaption></figure>

Claude Codeは毎回のやり取りで `CLAUDE.md` やこれまでの会話を送り直すため、入力トークンが積み上がります。それを抑えるのがプロンプトキャッシュで、キャッシュに当たった入力は基本単価の1/10です。Claude Codeは自動でキャッシュを使うので、`/usage` の「Prompt cache」の行でヒット率を確認できます。

実際にいくらかかるかは、公式ドキュメントに目安があります。**企業での平均は開発者1人あたり1日約$13、月$150〜250で、90%のユーザーは1日$30以下**です。ただしモデルの選択、コードベースの大きさ、複数インスタンスの実行や自動化の有無で大きく変わるので、小さなグループで試して自分たちの値を測るように書かれています。

## どのプランを選ぶか

料金ページの説明と、Claude Codeの解説動画で語られている使用感を合わせると、線引きは使う時間で決まります。

<figure class="post-figure"><img src="/media/images/claude-code-pricing/00_fig_choose.png" alt="Free・Pro・Max 5x・Max 20xの料金と向いている人を並べた図" loading="lazy"><figcaption>プランの選び方（日本の料金ページ、消費税込み、2026年9月18日）</figcaption></figure>

- **週に数回、個人開発や学習で使う**: Pro。Sonnet中心なら半日から1日は持つが、Opusで重い作業を続けると2〜3時間で上限に当たる、という報告が解説動画に複数あります
- **毎日数時間、仕事で回す**: Max 5x。上限に当たる回数が減り、1つの作業を止めずに終えやすくなります
- **終日回す、サブエージェントを並列で動かす**: Max 20x。動画では「1タスクでサブエージェントを4〜5個同時に走らせるなら5xでも足りない」と語られています
- **5人以上のチーム**: Team。個人のProを人数分契約するより、一元請求とSSOが付く分だけ管理が楽になります
- **自社サービスに組み込む、夜間に自動実行する**: API。定額プランの枠ではなく従量課金で設計します

迷ったらProから始めて、上限に当たる頻度を見てから上げるのが公式ヘルプの案内でもあります。年払いは月$18で約18%安くなりますが、数か月で使わなくなると残りが無駄になるので、最初の1〜2か月は月払いで様子を見る人が多いです。

## 使いすぎを防ぐ設定と確認方法

Claude Codeには使用量を見るコマンドが揃っています。

- `/usage`: 現在のセッションのトークン使用量と、5時間枠・週枠の残り。Pro・Maxでは使用クレジットの月間支出も出る
- `/usage-credits`: 使用クレジットの設定画面（claude.aiの設定＞使用状況）を開く
- `/insights`: トークン数ではなく作業の仕方のレポートを `~/.claude/usage-data/report.html` に書き出す
- `/context`: いま何がコンテキストを占めているか（MCPサーバー、CLAUDE.md、会話）

<figure class="post-figure"><img src="/media/images/claude-code-pricing/cc_06_docs_usage.jpg" alt="Claude Code公式ドキュメントの「コストを追跡する」の節。/usageコマンドの説明" loading="lazy"><figcaption>公式ドキュメントの「コストを追跡する」（2026年9月18日）</figcaption></figure>

TeamとEnterpriseでは、管理者が「管理者設定＞使用状況」でユーザーごと・組織ごとの月間支出上限を設定できます。

## 上級編。同じ作業でトークンを減らす3つの手

上位の解説記事にはあまり書かれていない、公式ドキュメントの「トークン使用量を削減する」の節から、効き目の大きい順に3つです。

### ① 作業の切れ目で /clear と /compact

トークンのコストはコンテキストの大きさに比例します。古い会話は後続のすべてのメッセージで送り直されるので、関係ない作業に移るときは `/clear` で新しく始めます。同じ作業が長引いたら `/compact` で要約し、`/compact Focus on code samples and API usage` のように残したい内容を指示できます。

### ② モデルを作業で使い分ける

ほとんどのコーディング作業はSonnetで足り、Opusは複雑な設計判断や多段の推論に取っておく、というのが公式ドキュメントの案内です。単価は入力でSonnet $2に対してOpus $5、出力で$10に対して$25なので、同じ作業なら2.5倍の差です。`/model` で切り替えられます。ただし前述のとおり、定額プランの上限はモデルをまたいで共通なので、上限回避の手段にはなりません。

### ③ 使っていないMCPサーバーを切る

MCPのツール定義は初期状態では遅延読み込みですが、接続しているだけで名前と指示はコンテキストに入ります。`/mcp` で一覧を見て、使っていないサーバーは無効にします。`gh`・`aws`・`gcloud` のようなCLIがあるものはMCPよりCLIのほうがコンテキストを食いません。

このほか、Claude Codeはアイドル中も会話の要約などで少量のトークンを使い（通常1セッション$0.04未満）、数時間開きっぱなしのセッションは見た目より多くの枠を消費します。使わないセッションは閉じるのが単純に効きます。

## よくある質問

検索で「claude code 料金」と一緒に出る関連質問（Googleの「他の人はこちらも質問」、2026年9月18日）を中心に答えます。

### Claude Codeは無料で利用できますか？

無料プランでは使えません。料金ページの機能比較表で、Claude Codeの行はFreeだけ「いいえ」です。使うにはPro（月$22）以上のプランか、APIキーでの従量課金が必要です。

### Claude CodeのProプランはどれくらい使えますか？

Anthropicは固定のメッセージ数を公開していません。5時間あたりの使用量はFreeの5倍以上で、会話の長さ・モデル・機能で変わります。解説動画ではSonnet中心の軽い作業なら半日から1日、Opusで重い作業を続けると2〜3時間で上限に当たると語られています。

### 有料プランは無料版と何が違いますか？

Claude Codeそのものが使えるようになるほか、Claude Design・Slides・Docs、プロジェクト、Claude in Chrome、Microsoft 365向けのClaude、Opusモデルが使えます。使用量もFreeの5倍以上です。

### Claude Codeは高いですか？

月$22のProで始められ、公式ドキュメントの企業平均は開発者1人あたり1日約$13です。Maxの$110・$220は毎日数時間から終日使う人向けで、上限で止まる時間をどれだけ減らしたいかで決まります。

### Claude Codeの料金はどこで確認できますか？

Claude Code内で `/usage` を実行すると、現在のセッションの使用量と5時間枠・週枠の残りが出ます。claude.aiの設定＞使用状況でも同じ内容と、使用クレジットの残高・今月の支出が確認できます。

### Claude Codeを使うのに追加料金はかかりますか？

Pro・Max・Teamに入っていれば、プランの枠内は追加料金なしです。上限を超えて使いたいときだけ、自分で使用クレジットをオンにすると超過分がAPI単価で請求されます。オンにしない限り追加請求はありません。

### Claude Codeの料金は日本円でいくらですか？

日本向けの料金ページはドル建てで消費税込みの表示です。Proは月$22、Maxは月$110と$220で、請求時のレートで円換算されます。1ドル150円ならProは約3,300円、Max 5xは約16,500円です。

### 年払いにしたほうがいいですか？

Proの年払いは月$18相当（$220一括）で、月払いの$22より約18%安くなります。Maxは月払いのみです。数か月で使わなくなる可能性があるなら、最初は月払いで上限に当たる頻度を見てから決めるほうが無駄がありません。
