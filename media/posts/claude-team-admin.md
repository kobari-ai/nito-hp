Claude Teamを契約したあとの管理は、組織設定（Organization settings）の［Members］にほぼ集まっています。Anthropicのヘルプ「[Team プランと Enterprise プランでメンバーを管理する](https://support.claude.com/ja/articles/13133750)」によると、メンバーの追加と削除は管理者以上が行えますが、請求の画面（Billing）に入れるのはオーナーとプライマリオーナーだけです。

招待と席と請求がそれぞれ違うタイミングで動くため、契約した直後につまずきやすくなります。**招待を送った時点で席が1つ埋まり、メンバーを外しても請求の席数は減りません。**この記事は2026年10月13日に取得したClaudeのヘルプセンターをもとに、招待・役割・席の変え方・個人のProからの移行を、契約した直後に触る順に説明します。管理画面そのものは撮っていないため、画像はヘルプのページと記述をもとにした図です。料金の金額やProとの違いは[Claude Teamプランの料金の記事](/media/claude-team/)にまとめています。

:::takeaways
- 招待は**［Members］から［Add member］でメールアドレスを入れる**。期限は21日で、保留中の招待もすぐに席を1つ使う
- メールのほかに**招待リンク（期限90日）・組織ディスカバリー・メンバー同士の招待**で人が入れる。リンクで入った人は承認なしで加わる
- 役割は4つ。**招待と削除は管理者から、請求とロールの変更はオーナーから、データのエクスポートはプライマリオーナーだけ**
- **メンバーを外しても席数と料金は減らない**。オーナーが席数を減らし、反映は次の更新日。日割りの返金はない
- 個人のProを持つ人が加わると、**両方残すか組織だけにするかを選ぶ**。組織へ持ち込んだ会話は個人に戻せない
:::

## メンバーを招待する手順

ヘルプの手順でいちばん先に出てくるのが、メールアドレスを指定する招待です。「招待によってメンバーを追加する」の節には次の5つの手順があり、管理者・オーナー・プライマリオーナーのどれでも操作できます。

1. Organization settings の［Members］を開き、［Add member］を押す
2. 相手のメールアドレスを入れる（組織が許可したメールドメインのものだけ）
3. 席の種類（Standard か Premium）を選ぶ
4. ロール（役割）と権限を決める
5. ［Add members］を押すと招待メールが届く

<figure class="post-figure post-figure--sp"><img src="/media/images/claude-team-admin/cta_02_help_invite_sp.jpg" alt="Claudeのヘルプで招待によってメンバーを追加する節をスマホで開いた画面。保留中の招待はすぐにシートを占有するという注記と、Add memberからAdd membersまでの手順を赤枠で囲んでいる" loading="lazy"><figcaption>Claudeのヘルプセンター（2026年10月13日、スマホ表示）</figcaption></figure>

**招待メールの期限は21日で、過ぎたら送り直しが必要です。**送り直しは［Members］の［Pending］タブで相手を探して行い、同じタブの［Remove from team］で招待の取り消しもできます。人数が多いときは［Bulk add］を使い、メールアドレスをカンマか改行で区切って貼り付ければまとめて送れます。

見落としやすいのが、ヘルプの冒頭の注記です。**保留中の招待は相手が受け入れる前から空いている席を占有します。**10席の契約で10人に招待を送れば、誰も参加していなくても席は満杯の扱いになります。席の種類の選択肢には契約にある種類だけが出て、その種類の席が全部埋まっていると、その場で買い足すよう求められます。

### 招待できるメールアドレス

Teamに招待できるのは組織が許可したメールドメインのアドレスだけです。最初に許可されるのは組織を作った人のドメインで、別のドメインを足すのはオーナーの役目になります。[アカウント管理に関するよくある質問](https://support.claude.com/ja/articles/13325567)にある手順は、［Identity and access］の［Domains］で［Add or edit domains］を押し、ドメインを入れて保存する流れです。

**組織を作る本人は会社のドメインのメールアドレスが必須ですが、ほかのメンバー用には@gmail.comのようなフリーメールのドメインも許可に足せます。**業務委託の人を個人のGmailで入れたい、という場面はここで対応できます。ただし後で出てくる招待リンクと組み合わせると、リンクを手に入れたGmailの利用者なら誰でも参加できてしまうため、フリーメールを許可した組織ではリンクを止めておくほうが安全です。

## 招待メール以外の参加の方法

メール招待のほかに、Teamには招待リンク・ディスカバリー・メンバー同士の招待の3つの経路があります。SSOを設定した組織ならIDプロバイダーからのJITプロビジョニングでも人が入ります。

| 参加の方法 | Teamの既定 | 審査 | 入ったときの席 |
|---|---|---|---|
| 招待リンク | 新しい組織ではオン | なし（リンクを開けば加わる） | 空いている中でいちばん下の種類 |
| 組織ディスカバリー | 新しい組織ではオン、前からある組織ではオフ | 自動承認か管理者の承認を選ぶ | 空いている中でいちばん下の種類 |
| メンバー同士の招待 | 新しい組織ではオン | 既定は1件ずつ管理者が承認 | 空いている中でいちばん下の種類 |
| SSOのJITプロビジョニング | SSOを設定した組織だけ | IDプロバイダー側で割り当て | 空いている中でいちばん上の種類 |

<figure class="post-figure"><img src="/media/images/claude-team-admin/cta_01_join_ways.jpg" alt="Claude Teamに人が入る4つの方法を並べた図。メール招待と招待リンクとディスカバリーとメンバー同士の招待のそれぞれに、審査の有無と期限を書いている" loading="lazy"><figcaption>参加の方法ごとの審査と期限（Claudeのヘルプセンターの記述から作成）</figcaption></figure>

SSOを入れた組織では、招待リンクと組織ディスカバリーは使えません。メンバーはIDプロバイダーの割り当てで入る仕組みに切り替わります。

### 招待リンクは審査なしで加わる

[招待リンク経由で組織に参加する](https://support.claude.com/ja/articles/13776697)のヘルプによると、リンクは管理者以上が発行・コピー・無効化・再生成できます。置き場所はこのページでは［ID とアクセス］のグローバルアクセス設定、メンバー管理のページでは［Organization and access］と書かれていて、2つのページで名前がそろっていません。

**リンクで参加した人は組織の承認の設定に関係なくいつも自動で追加されます。**加われるのは許可されたドメインのアドレスを持つ人だけですが、Slackのチャンネルに貼ったリンクが転送されれば、同じドメインの誰でも入れてしまいます。参加の前に確かめたい相手がいるなら、リンクではなく個別のメール招待を送るようヘルプにも書かれています。

<figure class="post-figure post-figure--sp"><img src="/media/images/claude-team-admin/cta_03_help_link_sp.jpg" alt="Claudeのヘルプで招待リンクの節をスマホで開いた画面。招待リンクは作成から90日後に自動的に期限切れになるという注意を赤枠で囲んでいる" loading="lazy"><figcaption>招待リンクの期限は作成から90日（Claudeのヘルプセンター、スマホ表示）</figcaption></figure>

期限が切れたら再生成して貼り直します。無効にすると既存のリンクがすべてすぐに止まり、再生成すると前のリンクは使えなくなります。空きの席が無いときの動きは、同じページに「標準シートが自動的に作成されます」という記述と「シート制限に達している場合はエラーが表示されます」という記述が並んでいます。どちらの動きになっても困らないよう、リンクを配る前に席の空きを確かめておきます。

### ディスカバリーの自動承認は席を買い足す

会社のメールアドレスでClaudeに登録しようとした人に、既存のTeamの組織を見つけて参加をリクエストさせる機能が組織ディスカバリーです。[組織ディスカバリーのヘルプ](https://support.claude.com/ja/articles/13566435)では、組織設定の［組織とアクセス］でドメインごとに検出可能のトグルを入れ、新規メンバーの承認を「自動承認」か「管理者承認が必要」から選びます。

**自動承認にすると、空きの席が無いときは請求が自動で広がり、新しい席がその場で購入されます。**社員が自分で登録するたびに席が増えるため、人数を予算で区切りたい組織は管理者承認を選ぶほうが安全です。管理者承認でも、承認した時点で空きが無ければ席は買われます。Gmailなどの個人用ドメインと.eduのドメインは、ディスカバリーの対象には入れられません。

## 4つの役割でできること

Teamの役割はユーザー・管理者・オーナー・プライマリオーナーの4つです。[ロールと権限](https://support.claude.com/ja/articles/9267276)の表から、管理の操作に関係する行を抜き出しました。

| 操作 | ユーザー | 管理者 | オーナー | プライマリオーナー |
|---|---|---|---|---|
| 新しいメンバーの招待 | | ○ | ○ | ○ |
| メンバーの削除・招待の取り消し | | ○ | ○ | ○ |
| 管理者・オーナーの招待と削除 | | | ○ | ○ |
| ロールの変更 | | | ○ | ○ |
| 請求書の表示と支払い・支払い方法の変更 | | | ○ | ○ |
| 連携・機能・プロジェクト共有の有効化 | | | ○ | ○ |
| 利用状況の分析を見る | | | ○ | ○ |
| データのエクスポートの依頼 | | | | ○ |

<figure class="post-figure"><img src="/media/images/claude-team-admin/cta_04_roles.jpg" alt="Claude Teamの4つの役割を階段状に並べた図。管理者は招待と削除、オーナーは請求とロールの変更、プライマリオーナーはデータのエクスポートが加わる" loading="lazy"><figcaption>上の役割ほどできることが増える（ロールと権限のヘルプから作成）</figcaption></figure>

**管理者は人の出入りを受け持つ役で、お金と権限の設定には触れません。**人の出入りだけを任せる担当者には管理者を、請求書を受け取る担当者にはオーナーを割り当てると、請求の画面を見せる相手を絞れます。メンバーの一覧は管理者以上が［Members］の［Export CSV］で書き出せて、名前・メールアドレス・ロール・席の種類が入ります。

ヘルプのページ同士で、席を買える役割の書き方がそろっていません。ロールの表では「新しいシートのプロビジョニング」にチェックがあるのはプライマリオーナーだけですが、[シートの購入と管理](https://support.claude.com/ja/articles/12004354)のページは「オーナーとプライマリオーナーのみがシートを購入」と書いています。英語版のロールの表も同じ並びでした。

### プライマリオーナーの譲渡

プライマリオーナーは組織に1人だけで、その席も契約の1席に含まれる決まりです。メンバーの会話やファイルを含むデータのエクスポートを申し込めるのはこの役だけで、[チームのデータの所有者のヘルプ](https://support.claude.com/ja/articles/9265372)では、メンバーの業務用アカウントと関連するデータをプライマリオーナーが管理すると説明しています。

**担当者の異動や退職が決まったら、最初の作業はプライマリオーナーの譲渡です。**譲渡は今のプライマリオーナーが［Members］で相手のロールの選択肢から［Primary Owner］を選び、確認の画面に相手のメールアドレスを入れて行います。オーナーとプライマリオーナーは自分で自分を組織から外せないため、本人が辞めてから気づくと別のオーナーの手が要ります。誰がプライマリオーナーかは設定の［アカウント］に表示されるので、まずそこを見てください。

## メンバーを削除する手順と請求

退職者が出たときの操作は2つに分かれます。最初はメンバーを外す作業で、［Members］で相手の右側のメニューから［Remove from team］を選びます。外れた人はその場で組織に入れなくなり、使っていた席は空席です。

**ただし外しただけでは契約の席数は変わらず、請求も日割りの返金もありません。**料金を下げるには2つ目の操作として、オーナーかプライマリオーナーが［Organization and access］の［Total seats］から［Manage］を開き、［Add or change seats］で減らしたい種類の「-」を押して確定します。減らした分が反映されるのは次の更新日で、年払いなら年の更新日です。

<figure class="post-figure"><img src="/media/images/claude-team-admin/cta_05_remove_billing.jpg" alt="メンバーを外してから請求が下がるまでの流れの図。メンバーを外すと席が空くだけで請求はそのまま、席数を減らすと次の更新日から請求が下がる" loading="lazy"><figcaption>外す操作と席数を減らす操作は別（シートの購入と管理のヘルプから作成）</figcaption></figure>

| 操作 | 誰ができるか | 請求への反映 |
|---|---|---|
| メンバーを外す | 管理者以上 | 変わらない（席が空くだけ） |
| 席を増やす | オーナー以上 | すぐ。残りの期間の日割りを請求 |
| 席を減らす | オーナー以上 | 次の更新日から。返金なし |

外した人を同じメールアドレスで招待し直すと、アカウントの履歴は残ったまま戻るとヘルプに書かれています。Teamを解約したあとは［Members］から外す操作ができなくなり、ヘルプは少ない席数で契約し直す前に外したいときはサポートに連絡するよう案内しています（[組織のTeamプラン購読をキャンセルする](https://support.claude.com/ja/articles/9267323)）。

## StandardとPremiumの切り替え

契約の総数の中であれば、席の種類は人ごとに入れ替え自由です。手順は［Members］で相手の［Tier］の選択肢から［Standard］か［Premium］を選ぶだけで、管理者以上が操作できます。Premiumの空きがあれば、StandardからPremiumへの変更は新しい購入ではなく割り当ての変更になります。

**上げる変更はすぐ反映されて差額の日割りがその場で請求され、下げる変更が効くのは次の更新日からです。**下げたときも日割りの返金はありません。請求額の計算のヘルプの年払いの例では、4月1日にStandard 5席をPremiumに上げると、残り275日分の差額として$3,616.44がその日に請求されています（米国向けの税抜き価格での計算例）（[Team プランの請求額はどのように計算されますか？](https://support.claude.com/ja/articles/9267289)）。

<figure class="post-figure post-figure--sp"><img src="/media/images/claude-team-admin/cta_06_help_tier_sp.jpg" alt="Claudeのヘルプでシートタイプ間でユーザーをスワップする節をスマホで開いた画面。No seat assignedを選んでPremiumの席を空け、別の人に割り当てる手順を赤枠で囲んでいる" loading="lazy"><figcaption>席を買わずに入れ替える手順（Claudeのヘルプセンター、スマホ表示）</figcaption></figure>

Premiumが全部埋まっていて、席を買わずにAさんとBさんの種類を入れ替えたいときは、［No seat assigned］を使います。Aさんを［No seat assigned］にしてPremiumを1つ空け、BさんをPremiumに、最後にAさんをStandardにする順番です。席の無い状態の人は組織に残りますが、席を戻すまでClaudeを使えません。

複数の人をまとめてPremiumからStandardに下げるなら、1人ずつ［Tier］を変えずに［Add or change seats］で種類ごとの合計を決めます。**予約できる席の変更は一度に1つだけで、新しい変更を出したり席を足したり招待が受け入れられたりすると、保留中の変更は置き換わります。**更新日の直前に新しい人を招待するときは、予約した減らす変更が残っているかを確かめ直してください。

## 個人のProから移るときの会話

会社のメールアドレスで個人のProやMaxを使っていた人がTeamに加わると、同じアドレスに個人用と組織用の2つのアカウントができます。[個人用のClaudeアカウントを組織に移動する](https://support.claude.com/ja/articles/9267400)のヘルプによると、選べるのは次の3つです。

| 選ぶもの | 個人のアカウント | 今までの会話 | Proの契約 |
|---|---|---|---|
| 両方のアカウントを保持 | 残る | 個人のほうに残る | 続く（請求も続く） |
| 組織だけにしてデータを持ち込む | 閉じる | 組織に移る | 自動で解約、日割りで返金 |
| 組織だけにしてデータを削除 | 閉じる | 移らない | 自動で解約、日割りで返金 |

<figure class="post-figure"><img src="/media/images/claude-team-admin/cta_07_migrate.jpg" alt="個人のProを持つ人がTeamに加わるときの3つの選択肢の図。両方を保持、データを持ち込む、データを削除に分かれ、データを持ち込むは戻せないと書いている" loading="lazy"><figcaption>持ち込みは一方通行（個人用アカウントの移動のヘルプから作成）</figcaption></figure>

Teamでは招待を受け入れるときに選ぶ画面が出て、その場で決めなくても7日ほど案内の帯が表示されます。あとから移すなら組織のアカウントに切り替えてから設定の［アカウント］で［個人用アカウントを閉じる］へ進みます。**データを持ち込むと、移った中身は個人のアカウントに戻せません。**

| 組織に移るもの | 移らないもの |
|---|---|
| チャットとチャット内のアーティファクト | カスタムスキル（先に書き出す） |
| プロジェクトと指示・ファイル | 連携したアプリのサインイン（入れ直す） |
| アップロードしたファイル | 自分で足したカスタムコネクタ |
| チャットとプロジェクトのメモリ（組織がメモリを切っている場合を除く） | 公開したアーティファクトと公開の共有リンク |
| Claude Codeのメモリと個人設定 | CoworkのセッションとClaude Codeのクラウドのセッション |

公開の共有リンクはずっと使えなくなるため、社外に会話のリンクを渡している人は移る前に別の方法で共有し直しておきます。App StoreでProを契約した人は、Appleの決まりで自動の解約ができず、選べるのは「両方のアカウントを保持」だけです。移った直後はチャットの一覧が出そろうまで時間がかかり、見つからないときはサインアウトして入り直すようヘルプに書かれています。

組織を作る本人が個人のProから申し込む場合は流れが少し違い、既定でそのアカウントがその場でTeamに切り替わります。その手順は[Claude Teamの料金の記事のProから移る節](/media/claude-team/)に載せました。

## 参加できないときの確認

招待したのに相手が入れないときは、次の5つを上から順に確かめます。

| 状況 | 確かめること |
|---|---|
| 招待メールが見当たらない | 21日の期限が切れていないか。［Pending］タブから送り直す |
| ドメインが違うと表示される | 相手のドメインが［Domains］の許可に入っているか |
| 席が空いているのに［Add member］が押せない | 受け入れられていない保留中の招待が席を使っていないか。取り消すか席を足す |
| 招待リンクが使えない | 90日の期限か、リンクの無効化・再生成。SSOの組織ではリンクは使えない |
| 加わったのに会社の画面にならない | 左下の名前から組織のアカウントに切り替える（青いチェックが今のアカウント） |

個人用と組織用のアカウントは同じメールアドレスでも会話とプロジェクトが別々です。**仕事の相談を始める前に左下のチェックが組織のほうに付いているかを確かめるよう社内で伝えておくと、業務の会話が個人のアカウントに残る事故を減らせます。**

席と役割を整えたあと、日々の業務の一部をAIに任せる仕組みづくりまで進めるときの進め方は、[AIエージェント構築支援](/ai-agent/)のページにまとめています。

## よくある質問

### Claude Teamでメンバーを追加するには？

組織設定の［Members］で［Add member］を押し、メールアドレス・席の種類・ロールを決めて［Add members］を押します。管理者・オーナー・プライマリオーナーが操作でき、招待メールの期限は21日です。

### Claude Teamに招待リンクはありますか？

あります。新しいTeamの組織では既定でオンで、管理者以上が発行できます。期限は作成から90日で、リンクで参加した人は承認なしで加わります。SSOを設定した組織では使えません。

### Claude Teamのオーナーと管理者の違いは何ですか？

管理者はメンバーの招待・削除と席の種類の割り当てまでで、請求の画面には入れません。オーナーはそれに加えて請求書と支払い方法、ロールの変更、管理者とオーナーの招待、連携や機能の有効化ができます。

### Claude Teamは削除で料金が下がりますか？

下がりません。席が空くだけで、契約の席数と請求はそのままです。オーナーが席数を減らすと次の更新日から反映され、日割りの返金はありません。

### Claude Teamの席の種類は変えられますか？

［Members］の［Tier］で人ごとに切り替えられます。Premiumに上げるとすぐ差額の日割りが請求され、Standardに下げる変更は次の更新日に反映されます。

### Claude Teamで削除した人の会話は？

組織に入れなくなりますが、同じメールアドレスで招待し直すとアカウントの履歴は残ったまま戻ります。会話を含むデータのエクスポートを申し込めるのはプライマリオーナーだけです。

### Claude ProからTeamに会話は移せますか？

組織だけにしてデータを持ち込むを選ぶと、チャット・プロジェクト・アップロードしたファイル・メモリが組織に移ります。カスタムスキルや公開の共有リンクは移らず、持ち込んだ中身は個人のアカウントに戻せません。

### Claude Teamで別のドメインの人を招待できますか？

オーナーが［Identity and access］の［Domains］でそのドメインを許可に足せば招待できます。組織を作る人は会社のドメインが必須ですが、メンバー用には@gmail.comなどのフリーメールのドメインも足せます。
