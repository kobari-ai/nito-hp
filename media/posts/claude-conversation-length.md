Claudeで長く話し続けると、1つの会話に入る量の上限に近づきます。上限に達すると「長さ制限」のエラーが出て、その会話では先に進めなくなります。

**2025年11月24日、Anthropicは会話が上限に近づいたときに前のメッセージを要約して続ける仕組みを入れました。**リリースノートによると、この変更で長さ制限のエラーは大幅に減り、いくつかの例外を除いて無限の長さの会話ができるようになりました。一方で、この仕組みにはコード実行をオンにしておく条件があり、長い会話は使用量を多く消費するという注意もヘルプに書かれています。

この記事ではAnthropicのヘルプ「[使用量と長さの制限はどのように機能しますか？](https://support.claude.com/ja/articles/11647753-how-do-usage-and-length-limits-work)」とリリースノートをもとに、長さ制限と圧縮の仕組み、設定、エラーが出たときの対処を整理します。

:::takeaways
- 長さ制限は**1つの会話に入る量（コンテキストウィンドウ）**の上限で、5時間や週間の使用制限とは別の仕組み
- 2025年11月から、上限に近づくと**Claudeが前のメッセージを要約して会話を続ける**。「考えを整理している」と出ることがある
- この自動の管理には**コード実行を有効にする必要がある**。設定の「機能」の「コード実行とファイル作成」
- 要約する長い会話は**使用量を多く消費する**。使用制限に近いなら新しい会話に移る
- Claude Codeでは上限に近づくと自動で圧縮され、**/compactで手動でも圧縮できる**
:::

## 長さ制限と使用制限の違い

「制限に達した」と出たときは、まずどちらの制限かを見分けます。ヘルプによると、**使用制限はすべての会話を通してどれだけ使えるか、長さ制限は1つの会話がどれだけ長くなれるか**を決めています。

| | 使用制限 | 長さ制限 |
|---|---|---|
| 何の上限か | 一定の時間に使える量 | 1つの会話に入る量 |
| 戻り方 | リセットを待つ・プランを上げる・使用量クレジットを買う | 新しい会話にする・プロジェクトを使う |
| 詳しい記事 | [Claudeの使用制限とリセット時間](/media/claude-usage-limits/) | この記事 |

長さ制限の元になっているのは、Claudeのコンテキストウィンドウです。ヘルプはこれをClaudeの作業用の記憶にたとえています。有料プランでチャットするときの大きさは、モデルによって100万・50万・20万トークンに分かれます。

| モデル（有料プランのチャット） | コンテキストウィンドウ |
|---|---|
| Claude Fable 5.1・Opus 5.5・Opus 5・Sonnet 5 | 100万トークン |
| Claude Fable 5・Opus 4.8・Opus 4.7・Opus 4.6・Sonnet 4.6 | 50万トークン |
| それ以外のモデル | 20万トークン（約500ページ以上のテキスト） |

表はヘルプ「[How large is the context window on paid Claude plans?](https://support.claude.com/en/articles/8606394-how-large-is-the-context-window-on-paid-claude-plans)」（2026年9月28日取得）の内容です。**コンテキストウィンドウの一部は、常にClaudeの回答のために取っておかれます。**

### 使用量を多く消費する

ヘルプには、自動コンテキスト管理が働くほど長い会話は、使用制限をより多く消費すると書かれています。**長いチャットで使用制限に近づいているなら、新しい会話を始めるよう勧めています。**

## 自動の要約をオンにする設定

自動コンテキスト管理を使うには、コード実行を有効にしておく必要があります。ヘルプ「[Claudeでファイルを作成・編集する](https://support.claude.com/ja/articles/12111783-create-and-edit-files-with-claude)」によると、Free・Pro・Maxプランではコード実行とファイル作成は初めから有効です。オフにしていたら、次の場所でオンにしてください。

1. [Claude](https://claude.ai/)で「設定」を開く
2. 「機能」を選ぶ
3. 「コード実行とファイル作成」をオンにする

<figure class="post-figure"><img src="/media/images/claude-conversation-length/ccl_02_help_code.png" alt="Anthropicのヘルプ、Claudeでファイルを作成・編集するのウェブとデスクトップで有効にするの節。Enterpriseプラン、Teamプランの説明の下に、Free、Pro、Maxプランは設定の機能からファイル作成を有効にし、コード実行とファイル作成をオンにしますという段落が赤枠で囲まれている。その下にコード実行とファイル作成の切り替えの画面の例がある" loading="lazy"><figcaption>ヘルプに書かれたコード実行のオンの仕方（2026年9月28日取得）</figcaption></figure>

スマホのアプリでは、左のサイドバーのイニシャルか名前を押して設定を開き、「機能」から切り替えます。TeamとEnterpriseでは組織の設定で初めから有効ですが、組織の所有者がオフにできます。**会社のアカウントで設定が見当たらないときは、組織の所有者に確かめてください。**

なお、エラーメッセージのヘルプでは、この仕組みの対象を「コード実行が有効になっている有料プランのユーザー」と書いています。使用量と長さの制限のヘルプでは「コード実行が有効になっているユーザー」で、プランの書き方がページによって違います（2026年9月28日時点）。

## 長さ制限のエラーが出たとき

自動の要約があっても、まれに長さ制限に当たることがあります。ヘルプ「[Claudeのエラーメッセージのトラブルシューティング](https://support.claude.com/ja/articles/12466728)」に載っている文言は「メッセージがこのチャットの長さ制限を超えます。ファイルを少なくするか、ファイルサイズを小さくするか、新しい会話を開始してください。」です。ヘルプが例に挙げているのは、とても大きな最初のメッセージを送った場合です。

ヘルプが挙げている対処は次の4つです。

- 内容を小さく分けて、1つずつ送る
- 送る前に、主要な部分を要約するか抜き出す
- Claudeに、いちばん関係のある部分を先に選ばせる
- 新しい会話を始める

**長さ制限は待っても戻らないため、送る量を減らすか、会話を分けてください。**大量の資料を扱うなら、プロジェクトに入れる手もあります。ヘルプによると、プロジェクトは関係のある内容だけを読み込む仕組み（検索拡張生成）を使うので、多くの情報を効率よく扱えます。

### 会話を圧迫するものを減らす

コンテキストウィンドウの大きさは変えられないものの、空きを増やす方法はヘルプに載っていました。

| 減らすもの | ヘルプの説明 |
|---|---|
| プロジェクトの指示 | 短く保ち、作業ごとの指示はチャットに書く |
| プロジェクトのファイル | 使っていないファイルを削除する |
| 拡張思考 | 深い推論が要らない作業ではオフにする |
| 努力レベル | 日常の作業では低い段階を選ぶ |
| ツールとコネクタ | 要らない会話ではウェブ検索・リサーチ・MCPコネクタを切る |

## Claude Codeでの圧縮

Claude Codeにも、会話が上限に近づいたときに前の履歴を要約して空きを作る自動の圧縮があります。ドキュメント「[Manage costs effectively](https://code.claude.com/docs/en/costs)」では、この上限に近いという警告は使用制限ではないと説明しています。

<figure class="post-figure"><img src="/media/images/claude-conversation-length/00_fig_where.png" alt="アプリとClaude Codeでの違いの図。Claudeのアプリはウェブ、デスクトップ、スマホで、コード実行がオンのとき上限に近づくと自動で要約する。長さ制限のエラーが出たら、ファイルを減らすか新しい会話にする。Claude Codeは上限に近づくと自動で会話を圧縮し、/compactで手動でも圧縮できる。/compactのあとに残したい内容を書き、作業を切り替えるなら/clear" loading="lazy"><figcaption>アプリとClaude Codeでの違い（Anthropicのヘルプとドキュメント、2026年9月28日取得）</figcaption></figure>

手動で圧縮するなら/compactです。**「/compact Focus on code samples and API usage」のように、残したい内容を続けて書くと、要約のときにそれを残すよう指示できます。**プロジェクトのCLAUDE.mdに圧縮のときの指示を書いておくこともできます。

関係のない作業に移るときは、圧縮より/clearで始め直すほうが軽い処理です。/compactは要約する会話を読み込むので大きな会話の圧縮はそれ自体が大きな処理になり、/clearは何も消費しない、とドキュメントに書かれています。

## よくある質問

### Claudeの長さ制限とは何ですか？

1つの会話に入る量の上限です。Claudeのコンテキストウィンドウに結びついていて、有料プランのチャットではモデルによって100万・50万・20万トークンです。

### Claudeの長さ制限は時間が経てば解除されますか？

解除されません。長さ制限は時間でリセットされる使用制限とは別の仕組みです。送る量を減らすか、新しい会話を始めてください。

### Claudeが考えを整理していると出るのはなぜですか？

会話が長くなり、前のメッセージを要約しているときの表示です。自動コンテキスト管理が動いている印だと、ヘルプは説明しています。

### Claudeで会話が要約されると前の内容は消えますか？

消えません。ヘルプによると、会話の履歴は全部保存されていて、Claudeは要約のあとも参照できます。

### Claudeの自動コンテキスト管理を使うには？

コード実行を有効にします。設定の「機能」から「コード実行とファイル作成」をオンにしてください。Free・Pro・Maxでは初めから有効です。

### 長い会話を続けると使用制限は早く減りますか？

減ります。自動コンテキスト管理が働くほど長い会話は使用制限をより多く消費する、とヘルプに書かれています。

### Claude Codeで会話を圧縮するには？

/compactと入力します。残したい内容を続けて書くと、要約のときにそれを残すよう指示できます。

### Claudeの会話を別の会話に引き継ぐには？

新しい会話を始め、前の会話の要点をまとめて最初に渡します。大量の資料を続けて使うなら、プロジェクトに入れると毎回渡さずに済みます。
