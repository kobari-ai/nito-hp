【2026年9月】Claude Coworkとは？使い方・できること・料金｜チャットとの統合で変わった点

Claude Coworkは、Anthropicが提供するClaudeの「作業を任せる」機能です。フォルダの中のファイルを整理する、複数の資料を読んでスライドにまとめる、サイトを開いて調べて表にする、といった複数の手順が要る仕事を、日本語で頼むだけで進めてくれます。

2026年9月時点で、1つ大きな変化が進行中です。AnthropicはCoworkとチャットをClaudeという1つの体験に統合する変更を段階的に進めており、新しい体験ではメッセージ欄で「Cowork」を選ぶ手順そのものがなくなります。この記事はAnthropicの公式ヘルプ（Cowork関連の記事10本、2026年9月20日取得）を一次ソースに、いまの画面と統合後の画面の両方を前提にして、できること、始め方、権限の設定、安全に使う条件までを書きます。

この記事のポイント
  • Coworkは目標を渡すとClaudeが手順を自分で組んで実行する機能。Claude Codeと同じ仕組みで、ターミナルが要らない
  • 使えるのは有料プラン（Pro・Max・Team・Enterprise）。デスクトップアプリ・ウェブ・スマホ・Chromeのサイドパネルから始められ、手元のファイルやブラウザを使う作業はデスクトップアプリが開いているときだけ
  • 権限は手動（既定）と自動の2つ。ファイルを完全に削除する前の確認は、どのモードでも既定で出る
  • できることは大きく6つ。フォルダの整理、資料の作成、ブラウザでの調査と入力、コンピュータの直接操作（ベータ）、定期実行、接続アプリの利用
  • 公式が使わないよう勧める領域がある。金融口座・契約・医療・他人の個人情報・行政の手続きは、ブラウザ操作やコンピュータ操作に任せない

Claude Coworkとは

公式ヘルプ「Claude Coworkを始める」の定義は、Claude Codeのエージェント機能をコーディング以外のナレッジワークにもたらすものです。プロンプトに1つずつ答えるのではなく、複数の手順が要るタスクを引き受けて代わりに実行します。公式ヘルプの言い方では望む結果を説明したら離れてよく、戻ると完成した作業（整えられた文書、整理されたファイル、まとめられた調査）を確認できる、とされています。

チャットのClaude Claude Cowork Claude Code
入口 ブラウザ・アプリの会話 デスクトップアプリ・ウェブ・スマホ・Chrome ターミナル・VS Code
向いている作業 質問・文章・相談 ファイル整理・資料作成・調査・定型業務 コードの修正・テスト・開発
ファイル 添付したものを読む 許可したフォルダを読み書きする プロジェクト全体を読み書きする
実行 しない サンドボックスで実行する ターミナルで実行する
使う人 誰でも 事務・企画・営業など エンジニア

解説動画（安野貴博「業務を自動化できるCoworkって何？」、にゃんた「ChatGPTやClaude Codeと何が違う？」）では、Claude Codeでできる作業は基本的にCoworkでもできるが、Claude Codeが黒い画面を使うエンジニア向けなのに対して、CoworkはそれをGUIにして全ビジネスパーソン向けにしたもの、と説明されていました。

チャットとCoworkが1つのClaudeに

公式ヘルプ「Claude Coworkとチャットが1つのClaudeに統合」によると、AnthropicはチャットとCoworkという2つの製品の区別をなくす新しい体験を、ウェブ・デスクトップ・モバイルのProとMaxプランから段階的に配信しています。同じプランでも配信の時期は異なり、有効にするための操作は要りません。

従来の体験 新しい統合体験
始め方 メッセージ欄で「Cowork」を選んで依頼 任意の会話で、同僚に頼むように依頼
権限の設定 手動承認・自動承認・すべての承認をスキップの3つ 自動と手動（既定）の2つ
会話の一覧 チャットとCoworkが別 短い質問と長いタスクが同じ一覧
引き継ぎ 既存のCoworkタスク・プロジェクト・コネクタ・スキル・アーティファクト・ファイルは引き継がれる

この記事の「始め方」は両方の画面で書きます。どちらの画面でも、できることと権限の考え方は同じです。

使える場所とプラン

Coworkは有料プランだけで使えます。始められる場所は4つあり、どこから始めてもタスクはアカウントに紐づくので、別の端末から進捗を見たり、成果物を受け取ったりできます。

場所 対応プラン 備考
デスクトップアプリ（macOS・Windows） Pro・Max・Team・Enterprise 手元のファイル・組み込みブラウザ・コンピュータ操作はここが開いているときだけ
ウェブ（claude.ai） Pro・Max・Team（ベータ）、Enterpriseは管理者が有効化 クラウドで実行
スマホ（iOS・Android） 同上 進捗の確認、質問への返答、外出先からの開始
Chromeのサイドパネル Max・Team。Proは配信中。Enterpriseは管理者が有効化 開くとそのままセッションが始まる

必要なものは、有料プランのアカウントとインターネット接続です。アプリを閉じるかオフラインになると、クラウドで動いているセッションからは手元のファイルが見えなくなります。

始め方

従来の画面（Coworkを選ぶ）

  1. claude.ai、Claude Desktop、またはスマホアプリを開く
  2. メッセージ欄で「Cowork」を選ぶ
  3. タスクを説明する（望む結果、形式、使ってほしい資料）
  4. Claudeが出す進め方を確認して、実行させる

統合後の画面（選ばずに頼む）

「Cowork」の選択肢はなく、どの会話でもそのまま頼みます。公式ヘルプは「同僚にブリーフィングするように」と表現しており、望む結果・形式・必要な入力を書くと、Claudeが答えるだけで済むか、タスクとして実行するかを判断します。

頼み方の例は公式ヘルプにいくつか載っています。

  • 「これら5つのインタビューノートを確認して、各テーマの引用とともに主要なテーマを抽出してください」
  • 「小規模チーム向けのトッププロジェクト管理ツールをリサーチして、比較をまとめてください。後で確認します」
  • 「この分析を月曜日にプレゼンできる10スライドのデッキに変換してください」
  • 「Downloadsフォルダをファイルタイプと日付で整理してください」

解説動画では「整理して」とだけ頼むと、Claudeがフォルダの中を見たうえで「種類別・日付別・プロジェクト別」の整理案を逆に提案し、選ぶと自動でフォルダを作って分類していく様子が映っていました。「曖昧な要件は質問して」「構成案の合意を取ってから作って」と添えると、対象者・目的・ページ数を聞き返してから作り始めるので、出来上がりの手戻りが減ります。

権限の設定と任せる範囲

Coworkで最初に決めるのが、Claudeがどこまで確認せずに進むかです。

設定 動き 向いている場面
手動（既定） 操作の前に毎回確認を求める。1つずつ許可する 最初の数回。メッセージ送信や重要ファイルの変更など、結果が戻せない作業
自動 確認で止まらずに進む。操作の前に自動の安全チェックが走り、危険と判断した操作は止める 要約・整理・下書きなど、やり直しが効く作業

従来の画面には「すべての承認をスキップ」もあり、これは自動チェックも行いません。統合後の画面では自動と手動の2つです。どちらの画面でも、ファイルを完全に削除する前の確認は既定で出ます。設定は会話の途中でも変えられ、作業中に止めたり方向を変えたりできます。

TeamとEnterpriseでは、管理者が自動承認の有効・無効を組織単位で決められ、書き込みを伴う操作ごとの承認を強制することもできます。

Claude Coworkでできること

① フォルダとファイルの整理・作成

デスクトップアプリで許可したフォルダの中を読み、整理し、ファイルを作ります。読み書きできるのは「信頼できるフォルダ」として接続したものだけで、ほかの場所には触れません。公式の例は「Downloadsフォルダをファイルタイプと日付で整理」です。

② 資料の作成

PowerPointで開けるスライド、数式が動く表計算、文書を作り、ダウンロードするかClaudeに続けて直させます。有料プランではClaude Design（ビジュアル）、Claude Slides（プレゼン）、Claude Docs（文書）のベータも使えます。解説動画では見積書・アンケート結果のExcel・業務時間の分析・事例レポートをまとめて読ませて、上司向けのAI導入提案スライドを作らせる実演がありました。

③ ブラウザでの調査と入力

デスクトップアプリに組み込まれた専用ブラウザか、Chrome拡張の「Claude in Chrome」を使って、サイトを開き、読み、クリックし、フォームに入力します。組み込みブラウザは既存ブラウザのログイン情報をサイト単位で読み込めますが、銀行・メール・SSOは既定で除外されています。

④ コンピュータの直接操作（ベータ）

ProとMaxのベータで、Claudeが画面をクリックし、入力し、アプリを直接使います。公式ヘルプによると、Claudeが使う道具の優先順位は①コネクタ→②ブラウザ→③画面操作の順です。macOS 15以降では裏のウィンドウで動くので、実行中も自分の作業を続けられます。有効にする場所はデスクトップアプリの「設定 > 一般」の「コンピュータ使用を有効にする」で、アプリごとのアクセス許可に答えてから使う流れです。

⑤ 定期実行のスケジュール

「毎週平日の午前8時に、チームのSlackチャネルの新しいメッセージを要約して」のように、毎時・毎日・毎週・平日で自動実行するタスクを作れます。クラウドで動くので、PCがスリープしていてもアプリを閉じていても走ります。その代わり、手元のフォルダには紐づけられず、コネクタかClaudeに保存したファイルで動かします。作り方は会話で頻度を伝えるか、タスク内で /schedule と打ちます。

⑥ 接続アプリの利用

Google Drive・Gmail・Microsoft 365・Slackなどを「カスタマイズ > コネクタ」で接続しておくと、タスクの途中で必要なものを取りに行きます。公式の例は「Driveで先四半期のボードデッキを見つけて、それ以来何が変わったかを要約して」です。

このほかに、関連するタスクをファイル・指示・記憶ごとまとめるプロジェクト、会話の中でダッシュボードや比較表を作るアーティファクト、頼んだ手順を覚えさせるスキルがあります。プロジェクトは「最初から」「Claudeのプロジェクトから取り込む」「コンピュータ上の既存フォルダを使う」の3通りで作れます。

タスクはどこで動いているか

自分のPCの中で何が起きているのかは、公式ヘルプ「Claude Coworkアーキテクチャの概要」に書かれています。使う側の目線で3つに分けると次のとおりです。

  • クラウドで動くセッション（既定・ベータ）: 作業とコードの実行は、Anthropicが管理する隔離された一時的なサンドボックスで行われ、セッションが終わると破棄されます。既定ではネットワークに出られず、許可された宛先にだけ通信します。会話の内容はClaudeの学習には使われません
  • 手元で動くセッション（デスクトップアプリ）: シェルコマンドやコードの実行は、PCの中の専用のLinux仮想マシン（macOSはApple Virtualization.framework、WindowsはHyper-V）の中で行われ、OS本体からは隔離されます
  • コンピュータ操作: ここだけはサンドボックスがなく、Claudeが画面のアプリと直接やり取りします。画面を理解するためにスクリーンショットを撮るので、機密のアプリやファイルは先に閉じておきます

手元のファイルにクラウドのセッションが触るときは、開いているデスクトップアプリを経由し、許可したフォルダの中だけを読み書きします。

安全に使うための線引き

公式ヘルプ「Claude Coworkを安全に使用する」は、使わないほうがよい領域をはっきり書いています。要点は5つです。

注意 内容
任せない領域 金融口座・投資・暗号資産、契約や法的文書、医療・健康情報、他人の個人情報、行政機関のサイト。ブラウザ操作やコンピュータ操作で扱わない
ファイルの渡し方 財務書類・認証情報・個人記録を含むフォルダにアクセス権を与えない。重要なファイルはバックアップし、専用の作業フォルダを作る
プロンプトインジェクション サイト・メール・外部文書に隠された指示にClaudeが従ってしまうリスクがある。外部の内容を読ませて、かつ操作の権限を与える組み合わせで起きやすい
戻せない作業 送金、自分名義のメッセージ送信、購入、重要ファイルの変更は、手動モードで、自分が近くにいるときに
スケジュール 見ていない間に動くので、まず要約・編集の低リスクな作業から。送信や購入は定期実行にしない。出力を定期的に確認する

指示していないファイルやURLに触り始めたり、頼んだ範囲を超えて作業が広がったりしたら、すぐに止める、というのも公式の案内です。ローカルのMCPサーバーはPC上で通常のプログラムと同じ権限で動くので、検証された拡張だけを使い、求められる権限を確認します。

料金

Coworkに追加料金はなく、Claudeの有料プランに含まれます。日本向けの料金ページ（claude.com/ja/pricing）は消費税込みの表示で、Proは月$22（年払いなら月$18）、Maxは月$110からです。使用量はチャットと同じ枠から減り、解説動画では「エージェントとして裏で動く指示が長いので、通常のチャットより枠に達しやすい」と説明されていました。プランの違いと上限の仕組みはClaude Codeの料金プランの記事に表でまとめています。

最初に試すとよい3つ

公式ヘルプが「まず低リスクな作業から」と勧めているので、やり直しが効くものから始めます。

  1. フォルダの整理: 専用の作業フォルダを作り、雑多なファイルを入れて「種類と日付で整理して」。何をどう分けるか、先に案を出させてから実行させる
  2. 複数の資料をまとめる: 会議メモを3〜5本入れて「共通するテーマを、根拠の引用つきで抜き出して」。出典が付くので確認しやすい
  3. 定期の要約: コネクタでSlackかDriveをつなぎ、「平日の朝に前日の新着を要約して」をスケジュールに登録する。出力を数日見て、内容が安定してから対象を広げる

よくある質問

Claude Coworkとは何ですか？

Claude Codeと同じエージェントの仕組みを、ターミナルなしでナレッジワークに使えるようにしたClaudeの機能です。目標を伝えると、Claudeが手順を組んでファイルの読み書き・調査・資料作成を実行します。

Claude Coworkは無料で使えますか？

使えません。Pro・Max・Team・Enterpriseの有料プランが必要です。追加料金はなく、使用量はチャットと同じ枠から減ります。

CoworkとClaude Codeの違いは何ですか？

同じエージェントの仕組みを使っています。Claude Codeはターミナルやエディタで動く開発向け、Coworkはデスクトップアプリやウェブから使う事務・企画向けです。公式ヘルプ「プロジェクトを使用してタスクを整理する」によると、プロジェクト機能はCoworkで使え、Claude Codeへの対応は今後の予定です。

Claude Coworkは日本語で使えますか？

日本語で問題ありません。指示も応答も日本語で通り、公式の例にある「Downloadsフォルダを整理して」のような頼み方をそのまま日本語で書けます。

Claude CoworkはWindowsで使えますか？

Windowsにも対応しています。デスクトップアプリはmacOSとWindowsに対応し、組み込みブラウザはLinuxもベータで対応しています。コンピュータ操作のベータの対象もmacOSとWindowsです。

Claude Coworkはパソコンを閉じても動きますか？

クラウドで動くセッションとスケジュールされたタスクは、アプリを閉じてもPCがスリープしていても動きます。ただし手元のフォルダ・組み込みブラウザ・コンピュータ操作を使う作業は、デスクトップアプリが開いている間だけです。

Claude Coworkで勝手にファイルを消されませんか？

ファイルを完全に削除する前の確認は、どの権限設定でも既定で出ます。手動モードなら、操作のたびに確認が出る設定です。公式ヘルプは重要なファイルはバックアップし、専用の作業フォルダで使うよう勧めています。

Coworkのスケジュールは何ができますか？

毎時・毎日・毎週・平日の頻度で、要約や調査などのタスクを自動実行できます。クラウドで動くのでPCがオフでも走りますが、手元のフォルダには紐づけられず、コネクタかClaudeに保存したファイルが対象です。送信や購入を伴う作業は定期実行にしないよう公式が案内しています。
