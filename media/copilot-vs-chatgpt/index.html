【2026年10月】CopilotとChatGPTの違い｜会社に入れるならどっち？料金・データ・管理

執筆 岡村 希一（nito代表）

MicrosoftのCopilot Businessの価格ページは、1人あたり月2,698円（年払い・税抜）と円で表示しています。OpenAIのビジネス向け料金ページでは、ChatGPT Businessの標準シートが1人あたり月20ドル（年額課金）です。どちらも2026年10月24日に開いたときの表示です。

1人あたりの金額は近くても、税の扱い・前提になる契約・社内データへの届き方は違います。この記事は会社でAIを入れる担当者に向けて、どちらを選ぶかの判断に要る違いを公式の資料で並べます。

  • ChatGPT Businessは米ドル建てで、直接の購入には消費税10%が加わる。2席から200席までで、データを日本に置けるのはEnterpriseだけ

比べる相手を先にそろえる

「Copilot」と呼ばれる製品はいくつもあり、比べる相手を決めないと話がかみ合いません。会社で検討の対象になるのは、Microsoft 365の利用者に追加費用なしで付くCopilot Chatと、有料のCopilotの2段です。プログラミング用のGitHub Copilotは別の製品で、この記事では扱いません。

有料のCopilotは会社の規模で2つに分かれます。Microsoft Learnのライセンスのページによると、Copilot BusinessはMicrosoft 365 Businessのライセンスを持つ300人までの組織向けのアドオンで、法人向けと同じCopilotの機能を提供します。300人を超える会社ではE3やE5などに足す法人向けのライセンスを使います。

LearnではMicrosoft 365 CopilotがMicrosoft Copilotに名前を変えたと書かれていますが、日本の価格ページは旧名のままなので、この記事は価格ページの名前で呼びます。

ChatGPTの会社向けは、自分で申し込めるBusinessと、営業を通して契約するEnterpriseの2つです。OpenAIのビジネス向け料金ページはBusinessを従業員数2〜200名のチーム向けとしています。両者の差は「ChatGPT Enterpriseとは」に書いています。

料金と最低席数

MicrosoftとOpenAIでは、価格の通貨と税の書き方が違います。Microsoftの価格ページはどのカードにも「価格には消費税は含まれていません」と添えた円の表示です。OpenAIの料金ページは米ドルで、日本の消費税のヘルプによるとOpenAIから直接買う場合は10%の消費税が請求され、適格請求書には税額が円で書かれます。Enterpriseのような個別契約の法人は、一般にリバースチャージの扱いで消費税は請求されません。

Microsoftの金額は税抜、ChatGPTの金額は消費税の前の値です。ChatGPTの料金ページのビジネス向けタブには、標準シートが3,050円（年額課金）・3,850円（月額課金）と円でも出ていました（2026年10月4日に確認）。2026年10月24日に開いたビジネス向けの料金ページでは、スタンダードシートは年額課金で月20ドル、月額課金で月25ドルです。席の数え方は「ChatGPT Businessとは」にまとめています。

Copilotの金額はCopilotだけの値段で、土台になるMicrosoft 365のライセンスは別に要ります。Copilot BusinessならBusiness BasicやBusiness Standardなど、法人向けならE3やE5などです。価格ページには土台とCopilotを組み合わせた価格もあり、Business Standardと組み合わせると年払いで月3,523円、月払いで4,228円です。ChatGPT Businessは単独で契約でき、Microsoft 365の有無は問いません。

最低の席数は両者で逆の向きに決まっています。Copilotは2024年1月のMicrosoftの発表で300席の最低購入数がなくなり、1人から買えます。ChatGPT Businessは最低2席で、1つの契約の上限が200席です。

年払いで50人に配ったときの月額です。Copilotの土台のライセンスは含めていません。

Microsoft 365を使っているか

最初に確かめたいのは社員がすでにMicrosoft 365のアカウントで働いているかどうかです。価格ページのFAQでは、Copilot Chatは対象のMicrosoft 365プランの利用者に追加費用なしで含まれるWebを根拠にしたAIアシスタントと説明されています。有料の契約を決める前に、社員はもう会社の管理下にあるAIチャットを持っていることになります。

Copilot Chatの概要にある表では、何を根拠に答えるかが入口ごとに分かれています。

入口 何を根拠に答えるか
Copilot Chat（Web・アプリ） Web、本人が渡したファイル、対応するアプリの文脈
OutlookのCopilot Chat 受信トレイ・予定表・会議・チャットと限られた関連の内容
有料のCopilot Microsoft Graph、Work IQ、Microsoft 365全体の索引

Copilot Chatのままでは、Word・Excel・PowerPoint・OneNoteの中でCopilotのチャットは使えません。ファイルのアップロードや画像の生成はできますが、混んでいるときは有料の利用者が優先されます。

Google Workspaceで働いている会社がCopilotを入れるなら、Microsoft 365のライセンスから買う必要があり、ChatGPT Businessのほうが手前で済むでしょう。ChatGPTの料金ページにも、BusinessでGoogle Workspace・Slack・GitHub・Microsoft 365などと連携できるとの記載があります。Google WorkspaceのGeminiと比べるなら「CopilotとGeminiの違い」で同じ順番に並べました。

Microsoft 365の会社なら、Copilot Chatで足りない仕事を書き出してから有料のCopilotを配る人を選ぶと無駄が出にくくなります。配ったあとの利用の確かめ方は「Copilotが社内で使われないときの調べ方」で扱いました。

TeamsとOutlookの中で使えるか

有料のCopilotはアプリの中に入ります。Microsoftの価格ページに並ぶのは、Word・Excel・PowerPoint・Outlook・Teamsなどのアプリ内のCopilotと、Teamsのチャット・通話での利用です。ユースフルの解説動画ではCopilot ChatだとOutlookの横のチャットで下書きを作って貼り付ける手間が残り、有料版だと返信欄に直接下書きが入る違いが実演されていました。

ChatGPTはChatGPTの画面で使うのが基本です。料金ページの比較表ではBusinessでExcel・PowerPoint・Googleスプレッドシートの拡張機能が標準で付き、Microsoft 365とつなぐアプリもあります。1日の仕事がOutlookとTeamsの中で終わる人にはCopilotが近く、資料の下調べや長い文章を別の画面で練る人にはChatGPTの使い方が合います。

社内データへのつなぎ方

Copilotが答えに使う社内のデータは、本人が少なくとも閲覧できるものだけです。Learnのデータとプライバシーのページによると、メール・予定表・チャット・会議・文書にMicrosoft Graphを通して届き、SharePointなどの権限をそのまま守ります。裏返すと、全社に共有されたままの人事や給与のファイルがあれば答えの材料になり得るため、導入の前にSharePointの共有設定を見直しておく必要があります。

Microsoft 365の外のシステムをつなぐ仕組みがCopilotコネクタです。中身をMicrosoft Graphに取り込む同期型と、MCPを使ってその場で取りに行く取り込まない型があり、どちらも元のシステムの権限を守ります。

ChatGPTからMicrosoft 365のファイルを読むときは、SharePointアプリを使います。対象は職場のSharePointとOneDriveで、個人用のOneDriveは対象外です。組織で管理者の同意が必要な設定なら、先にMicrosoft Entraの管理者が権限を承認しないと使えません。ヘルプはライブで読むためにSites.Read.AllとFiles.Read.Allを挙げ、ChatGPTのワークスペース管理者とEntraの管理者が別の人のことがあると書いています。

読める範囲はつないだMicrosoftアカウントの権限に従うので、権限の見直しが要るのはChatGPTでも同じです。アプリを有効にする手順は「ChatGPTのコネクタの管理」で扱っています。

学習の扱いと保存場所

入力が学習に使われない点は、どちらの会社向けの契約でも公式に書かれています。差が出るのは保存場所と、管理者が会話をどう扱えるかです。

項目 Copilot ChatGPT Business ChatGPT Enterprise
入力を学習に使うか 使わない 既定で使わない 既定で使わない
データを日本に置けるか 日本のテナントは製品条項の対象 対象外 日本を含む10地域から選ぶ
会話の保持と検索 Purviewの保持ポリシーとコンテンツ検索 公式の比較表に記載なし 管理者が保持期間を設定、Compliance API

Copilotは製品条項のデータ所在地の対象に、Microsoft 365 Copilotが2024年3月1日、Copilot Chatが2025年9月1日に加わりました。既定の地域が日本のテナントなら、Copilotとのやり取りも日本に保存される約束に入っています。ただしWebの検索に使う短い語句はBingに送られ、Microsoft 365とは別の扱いになるとエンタープライズ データ保護のページにあります。

ChatGPTでデータを日本に置けるのは、新しく導入するEnterpriseとEduです。Businessは料金ページの比較表でデータレジデンシーの対象外です。

ChatGPT Businessのワークスペース管理者は、メンバーの会話履歴を閲覧・エクスポート・削除できるとエンタープライズ プライバシーのページのBusinessのFAQにあります。Businessのデータ共有のヘルプが書いているのは、ほかのメンバーには会話が自動で表示されないことと、利用状況の分析や支出管理の画面から会話は見えないことです。管理者がどの画面から会話を開けるかはヘルプに手順が見当たらないため、社内規程で会話の監査が要る会社は、契約の前にOpenAIの営業かサポートに確かめておくべき項目です。

管理者が設定するところ

Copilotは社員のMicrosoft 365のアカウントと権限をそのまま使うため、管理の場所が増えません。ライセンスはMicrosoft 365管理センターで割り当て、エージェントは統合アプリの画面で許可し、従量課金はCost Managementで上限を決めます。割り当ての手順は「Copilotのライセンスを割り当てる方法」にあります。

ChatGPTはMicrosoft 365とは別の管理コンソールを持ちます。料金ページの比較表で、BusinessとEnterpriseの差は次のとおりです。

機能 ChatGPT Business ChatGPT Enterprise
SAML SSO・ドメイン認証 あり あり
SCIM（アカウントの自動追加と削除） なし あり
ロールベースのアクセス制御 なし あり
IP許可リスト なし あり
Compliance API なし あり

Entra IDとSAMLでつなげばBusinessでも会社のアカウントでサインインできますが、退職者のアカウントを自動で外すSCIMはEnterpriseだけです。SCIMの無いBusinessでは退職者をワークスペースの画面で外す運用になり、その手順は「ChatGPT Businessのメンバー招待と管理」にまとめています。

両方入れる会社の例

全社でCopilotを買ったあとにChatGPTも使われるようになった例は報じられています。Bloombergの2025年6月24日の記事によると、製薬のAmgenは前の年の春に2万人分のCopilotの購入を発表し、13か月後には社員がChatGPTを使っていました。同じ報道を伝えたTom's Guideは、社員がChatGPTも使っていると書いています。

両方を入れると費用が二重になるうえ、社員が使う画面・データの保存場所・管理の画面も2つずつです。分けるなら、全員にはCopilot Chatを使ってもらい、資料づくりが多い部署にだけChatGPT Businessを配るように、誰がどちらを使うかを先に決めておくと迷いが減ります。どちらを入れる場合も、個人で契約したAIに業務のデータを入れてよいかを社内の規程で決めておきます。規程の作り方は「シャドーAIの対策」が参考になります。

個人の無料版の違い

個人で使う無料のCopilotアプリとChatGPTの無料版は、どちらも会社の契約の外のサービスです。上の表の学習の扱い・保存場所・管理者の設定は会社向けの契約の話で、個人のアカウントには当てはまりません。

ChatGPTの無料版・Go・Plusでは「すべての人のためにモデルを改善する」の設定がオンだと、入力が学習に使われることがあると接続済みアプリのヘルプにもあります。個人で使い続けるなら、設定を確かめておきましょう。手順は「ChatGPTに学習させない設定方法」にあります。

よくある質問

CopilotとChatGPTは同じAIですか？

同じではありません。CopilotはMicrosoftの製品で、Microsoft 365の権限とデータの上で動きます。ChatGPTはOpenAIの製品で、独自の画面とワークスペースを持ちます。

Copilotの中身はChatGPTですか？

ChatGPTそのものではありません。LearnによるとCopilotはOpenAIのモデルを使い、Anthropicのモデルも管理者が許可すれば使えます。答えの根拠になる社内データの扱いはMicrosoftの契約に従います。

CopilotとChatGPTはどちらが安いですか？

1人あたりの年払いではCopilot Businessが2,698円（税抜、割引の表示）、ChatGPT Businessが20ドル（消費税の前）で近い金額です。Copilotは土台のMicrosoft 365のライセンスが別に要るため、Microsoft 365を使っていない会社ではChatGPTのほうが安く済みます。

CopilotはMicrosoft 365なしで使えますか？

有料のCopilotはBusiness BasicやE3などの対象のMicrosoft 365のライセンスがある人に足す契約なので、単独では買えません。Microsoft 365を使っていない会社は、そのライセンスからの契約です。

Copilot Chatは無料で使えますか？

対象のMicrosoft 365プランを使っている人なら、追加費用なしで使えます。Webを根拠に答え、渡したファイルも読めるものの、Word・Excel・PowerPoint・OneNoteの中のCopilotのチャットには有料のCopilotが必要です。

ChatGPTはSharePointのファイルを読めますか？

SharePointアプリを使えば読めます。組織で管理者の同意が必要な設定なら、先にMicrosoft Entraの管理者がSites.Read.AllやFiles.Read.Allなどの権限を承認しておく形です。

CopilotとChatGPTの入力は学習に使われますか？

会社向けの契約ならどちらも使われません。Copilotのプロンプトと応答は基礎モデルの学習に使われず、ChatGPT BusinessとEnterpriseは既定で学習に使われない設定です。

ChatGPTのデータは日本に保存できますか？

新しく導入するChatGPT EnterpriseとEduなら日本を選べます。Businessはデータレジデンシーの対象外です。
