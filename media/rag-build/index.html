RAG構築とは

RAG（検索拡張生成）は質問のたびに社内の文書から関係する箇所を探し、その箇所をAIに渡して答えさせる仕組みです。AIが社内文書を覚えるわけではないので、直した規程を取り込み直せば次の質問から新しい版で答えます。文書を取り込んで探せる形にし、探した結果をAIに渡す流れを自社用に組むのがRAG構築です。 文書を断片に切って探す4段の流れは社内チャットボットの選び方で図にしました。ここではその流れを作る側の決めごとを扱います。

AIエージェントが道具の1つとして社内文書を探すときも、その中身はRAGと同じです。エージェントそのものの説明はAIエージェントとはにあります。

RAG構築の作り方は3通り

検索の部分をどこまで自分で持つかで、作り方は3つに分かれます。

①既製品の機能 ②ノーコード・ローコード ③クラウドの部品
例 M365 Copilotのエージェント ビルダー・GeminiのGem・ChatGPT Businessのプラグイン Dify・Copilot Studio・n8n Azure AI Search・Amazon Bedrock ナレッジベース・Google Agent Search・OpenAIのファイル検索
向く会社 社員の大半が同じ業務基盤を使っている 担当者が画面で設定を詰められる 自社のシステムや画面に組み込みたい
試作までの手間 契約の中ですぐ試せる アカウントと文書の取り込み 開発者がAPIをつなぐ
費用の数え方 1人あたりの月額に含まれる プランの月額とモデルの代金 保存量と質問の回数
保守 提供元が直す 設定と取り込みは自社 全部自社か外注先

選ぶ基準は答えが外れたときにどこまで自分で直したいかです。 ①は直せる所が少ない代わりに保守が要らず、③は分け方から権限まで全部を決められる代わりに直す人が要ります。AIエージェント全体の作り方を3通りに分けたAIエージェントの作り方では、Copilot Studioを既製の基盤の例に置きました。文書の取り込みと検索の設定を画面で触れるため、RAGの話では②に入れています。

既製品の機能で作る

Microsoft 365・Google Workspace・ChatGPT Businessの契約があれば、その中で文書に答えるボットを作れます。M365 Copilotのエージェント ビルダーはSharePointのファイルを100個まで読み、GeminiのGemはGoogleドライブの最新の版を使います。分け方や探し方は選べません。規程集やマニュアルのように文章が中心の文書から始める用途に向き、基盤ごとの上限と共有の範囲は社内チャットボットの選び方で比べました。

ノーコード・ローコードで作る

Difyは文書の切り方と探し方を画面で選べる道具です。Difyのチャンク設定には、すべての断片を同じ区切り文字と最大の長さで切る汎用モードと、小さな断片で探してその断片を含む大きな断片を返す親子モードがあります。Copilot Studioはファイルのアップロードで500個までのファイルを持たせられ、SharePointにもつなげます。n8nは業務の自動化の流れに検索を差し込む使い方が中心です。料金はそれぞれDifyの料金・Copilot Studioの料金・n8nの料金にまとめました。

クラウドの部品で組む

自社の業務システムや社外向けの画面に組み込むなら、クラウドの検索の部品を使います。Amazon Bedrockのナレッジベースの概要によると、Managed Knowledge BaseはS3・SharePoint・Confluence・Googleドライブ・OneDriveにつなぎ、文書ごとの権限で検索結果を絞れます。 自分で検索の土台を選ぶ従来の型では、外部へのコネクタと文書単位の権限は使えません。Googleのドキュメントでは2026年4月からVertex AI SearchがAgent Searchの名前に変わり、Google Cloud コンソールの画面は今もVertex AI SearchとAI Applicationsの名前のままです。社内データの検索を含む全体はGemini Enterpriseの範囲です。

RAG構築の手順

技術の面の手順は文書の収集・分割・ベクトル化・検索・回答の生成の5段です。会社で作るときはその前後に目的の決定と権限・運用が入ります。

目的と問いを決める

人事・総務・情シスに届いた質問を集め、答えに使う文書がはっきりしている質問から30〜50問を選びます。だれのどんな質問に答えさせるかが決まらないと、入れる文書も決まりません。この質問の一覧が後の手順で答えを確かめる試験問題になります。

文書を集めて整える

対象の質問に答える文書の最新版だけを集めます。旧版や下書きが混ざるとAIは古い規程を根拠に答えてしまうため、置き場所は1か所にまとめます。断片に切った後も何の文書か読み取れるよう、文書名・改定日・対象者を文書に添えておくのが基本です。

分け方と探し方を決める

Microsoftのチャンク分割の解説は、200語や600文字ほどの固定の長さに10〜15%の重なりを持たせる方法を最初に挙げています。OpenAIのファイル検索の既定は800トークンで、隣り合う断片と400トークンを重ねる設定です。意味の近さで探すベクトル検索と語の一致で探す全文検索を組み合わせるハイブリッド検索も、各社の部品で選べます。

答えの確かめ方を決める

選んだ質問を流し、正しい文書の断片が返ったかと答えが文書に沿っているかを見ます。正解の文書と答えを質問と組にしておけば、設定を変えるたびに同じ問題で比べられるでしょう。

質問: 立て替えた交通費はいつまでに申請する？
正解の文書: 経費精算規程（2026年4月改定）第5条
正解: 翌月5日まで

権限とログを決める

だれがどの文書の中身を答えとして受け取れるかを、元の文書の権限に合わせます。質問と答えと使った文書のログを、どこに何日残すかもこの段階で決めておきます。

運用で直し続ける

答えられなかった質問と、利用者が誤りと指摘した答えを週に1度読み、足す文書と直す設定を決めます。文書の持ち主と設定を直す人は、分けて名前で決めておくのが前提です。

RAG構築でつまずく所

各社の公式の文書に書かれた仕様のうち、作り始めてから気づきやすいものを4つ挙げます。

表や図の多いPDF

既定の読み取り方のままだと、表や図の中身が失われることがあります。 Amazon Bedrockで検索の土台を自分で選ぶ従来の型では、解析の設定によると既定のパーサーがテキストだけを取り出します。そのため図・グラフ・表・画像を含む文書には、Bedrock Data Automationか基盤モデルでの解析を勧めています。Managed Knowledge Baseは表や画像も読む解析が標準で付き、追加の料金はかかりません。Googleのドキュメントの解析とチャンク化でも、既定のデジタル パーサーは表・リスト・見出しを検出しません。料金表や手当の一覧が表で書かれた規程なら、解析の方法を変えて試すか、表を文章に直してから取り込みます。

Copilot Studioに上げたファイルの画像はPDFに埋め込まれたものだけが対象で、代替テキストを付けておくと画像の情報からも答えられます。秘密度ラベルやパスワードで暗号化したファイルも上げられない仕様です。

分け方を後から変えられない

Difyのナレッジベースは、作った後に汎用か親子かのチャンクモードを変えられません。高品質のインデックスで作ったものを、エコノミーへ切り替えることもできない仕様です。試作の段階で2つのモードを別のナレッジベースとして作り、同じ質問で比べてから本番の形を決めます。

権限が検索に効かない

元のフォルダーで見られない社員でも、取り込んだ後の検索では中身が出てしまうことがあります。Azure AI Searchのドキュメント レベルのアクセス制御では、SharePointの権限や秘密度ラベルをそのまま使う方法が2026年10月31日時点でプレビューでした。一般提供の方法で作るなら、文書にだれが見られるかの情報を持たせて検索のたびに絞り込みます。

n8nのSimple Vector Storeは検証だけに使う置き場です。 n8nのドキュメントによると、データはメモリにだけ置かれ、n8nを再起動するとすべて消えます。保存先のキーもワークフローごとに分かれておらず、同じn8nを使う全員が読めてしまいます。

答えの確かめ方がない

試験問題を作らずに公開すると、設定を変えたときに良くなったのか悪くなったのかが分かりません。Amazon BedrockのRAGの評価の指標は、検索だけの評価と検索と答えの両方の評価に分かれています。返した断片が正解の文章の情報をどれだけ含むかを測る指標には、正解を添えた質問の一覧が必要です。答えが取り出した文書に沿っているか、引用が正しいかを見る指標も並んでいます。

RAG構築の費用

費用は作る人の時間・検索の部品・答えを作るモデルの3つに分かれます。 このうち公式の料金表で数えられるのは検索の部品とモデルの代金です。2026年10月31日に各社の料金ページで確かめた単価を並べました。

部品 保存 質問
Azure AI Search Basic（東日本） 1時間0.133ドルの定額で15GBまで 定額に含む
Amazon Bedrock Managed Knowledge Base 元データ1GBあたり月5ドル 1,000回あたり1ドル
Google Agent Search 1GiBあたり月約5ドル（月10GiBは無料） Standardは1,000回あたり1.5ドル（月1万回の無料トライアルあり）
OpenAIのファイル検索 1GBあたり1日0.1ドル（1GBは無料） 1,000回あたり2.5ドル

Azureの金額はMicrosoftの価格APIで東日本の単価を引き、月730時間で数えています。Bedrockは文書の解析・ベクトル化・並べ替えに標準のモデルを使う限り0ドルで、自分で選んだモデルを使うと別料金です。OpenAIの保存量は元のファイルでなく、切った断片と埋め込みの大きさで数えます。GoogleのEnterpriseは1,000回あたり4ドルで、検索結果からの答えの生成まで含みます。

同じ前提で月額を試算しました（試算。文書2GB・月1万回の質問を仮定し、答えを作るモデルの代金は含めていません）。円は三菱UFJ銀行の公示仲値1ドル157.54円（2026年10月30日）での換算です。

部品 試算の内訳 月額
Azure AI Search Basic 0.133ドル×730時間 約97ドル（約1.5万円）
Bedrock Managed Knowledge Base 2GB×5ドル＋1万回×1ドル/1,000回 20ドル（約3,200円）
Google Agent Search Standard 保存・回数とも無料枠の範囲 0ドル
OpenAIのファイル検索 超過1GB×0.1ドル×30日＋1万回×2.5ドル/1,000回 28ドル（約4,400円）

この規模なら検索の部品の代金は月0円から1.5万円ほどに収まります。 Bedrockの料金ページの例でも、SharePointから50GB・約10万文書を取り込んで月10万回検索し、月350ドルです。従来の型で表の多い文書をData Automationで解析すると1ページ0.01ドルかかり、1,000ページで10ドルになります。予算を左右するのは部品の単価より、文書を整えて試験問題を作り、答えを直し続ける人の時間です。

自社で作るか外に頼むか

外に頼む費用は対象の文書の量と権限の条件、公開後の運用まで頼むかで変わります。金額を比べる前に、次の条件で自社と外のどちらが向くかを決めます。

条件 向く方
既製品の機能かノーコードで足り、設定を直す担当者を置ける 自社で作る
自社のシステムや社外向けの画面に組み込む 外に頼むか開発者を置く
文書ごとの権限を検索に効かせる必要がある 外に頼むか開発者を置く
公開後に試験問題を回して直す人を社内に置けない 運用まで含めて外に頼む

試験問題の質問と正解・文書の持ち主は外に頼む場合でも社内で用意するものです。対象の質問・文書の量・権限の条件・ログの残し方の4つを書面にしてから見積もりを取ると、各社の答えを同じ形で比べられます。

会社が決めること

作り方より先に社内で決めることが5つあります。

  • 対象の質問：だれのどんな質問に答えさせるかと、試験に使う30〜50問
  • 最初に入れる文書：対象の質問に答える最新版だけ。表の多い文書は解析の方法も
  • 権限の扱い：元の文書の権限を検索に効かせるか、全員が見てよい文書だけにするか
  • ログと保存場所：質問と答えをどこに何日残すか、データをどの地域に置くか
  • 直す人：文書の持ち主と、設定を直す担当の名前

よくある質問

RAG構築はCopilotやGemの機能でできますか？

社内規程やマニュアルのように文章が中心の文書なら、M365 Copilotのエージェント ビルダー・GeminiのGem・ChatGPT Businessのプラグインで作れます。断片の切り方や探し方は選べません。表の多い文書や自社のシステムへの組み込みが要るなら、②か③の作り方に進みます。

Amazon BedrockのRAGは月いくらですか？

Managed Knowledge Baseなら保存が元データ1GBあたり月5ドル、検索が1,000回あたり1ドルです。文書2GB・月1万回の試算では検索の部品が月20ドルで、答えを作るモデルの代金が別にかかります。

Azure AI Searchで権限は効きますか？

SharePointの権限をそのまま使う方法は、2026年10月31日時点でプレビューです。一般提供の方法で作るなら、文書にだれが見られるかの情報を持たせて検索のたびに絞り込みます。

Difyのチャンクの設定は後から変えられますか？

区切り文字や最大の長さはいつでも変えられます。汎用か親子かのチャンクモードは、ナレッジベースを作った後には変えられません。

n8nで作ったRAGのデータは消えますか？

Simple Vector Storeに入れたデータは、n8nの再起動で消えます。本番では外部のベクトルデータベースのノードに保存先を変えてください。

Agent Searchの旧名は何ですか？

Vertex AI Searchです。Googleは2026年4月にドキュメントでの名前をAgent Searchに変え、ほかの場所の名前も変えている途中です。Google Cloud コンソールの画面では今もVertex AI SearchとAI Applicationsの名前で表示されます。

RAG構築を外注するといくらかかりますか？

対象の文書の量や権限の条件、運用まで頼むかで費用は変わります。対象の質問・文書の量・権限の条件・ログの残し方を書面にそろえ、複数の会社から見積もりを取って比べます。
